## 핵심 결론 (Answer-first)

1. **VisaDesk가 노리는 "채용 이후 × E계열 고용기업 준법 원장(System of Record)"은 2026.6 현재 직접 경쟁자 0 — 단, 인접에서 빠르게 좁혀오는 중.** 가장 위협적인 인접은 **Hirevisa(하이어비자, 운영사 하이어다이버시티)**: vivisa와 동일한 "대학판 VisaDesk" 포지션이지만 트랙션이 압도적이다(서울 유학생 82,596명 중 **81%+ 커버·40개+ 제휴대학·94개 학과** [출처:Hirevisa, '24.2 기준] / **시드 10억원** [출처:Hirevisa·스톤브릿지벤처스]). 이들이 D-10→E-7 취업전환 구간을 타고 **기업 고객으로 북상하면 우리와 정면 충돌**한다. **이것이 팩 #10·핸드오프가 못 잡은 신규 발견이다.**
2. **현재 E계열 고용기업의 실질 incumbent는 SaaS가 아니라 ① 고용허가제 업무대행기관(중기중앙회·농협·수협 등 노동부 위탁) + ② 개별 행정사·노무사 + ③ 엑셀+캘린더 수기**다. 즉 우리의 진짜 경쟁자는 "소프트웨어"가 아니라 **"사람+종이"** — 카테고리 자체가 미개척(blue ocean)이며, 이는 시장 매력도(기회)인 동시에 **"카테고리 교육 비용(category-creation cost)"** 리스크다.
3. **vivisa×클링커즈(glow) 신용스코어 동맹은 "길목 경고"이되 아직 속도 위협은 낮다.** MOU는 **2025.12.18 체결**(언론 보도 12.19~12.23) · **추진방식 "단계적"·런치일·구체 모델 스펙 없음** [출처:서울경제 2025-12-19·벤처스퀘어]. ForeignID L2/L3 + 고용·임금 데이터를 PoC에서 즉시 축적하면 **데이터 선점에서 우리가 앞선다** — 단 분기 워치 필수.
4. **right-to-win = 양면 데이터 결합(고용 B2B 원장 × 환급/금융 B2C 결과)을 동시에 가진 곳이 우리뿐**이라는 점이다. 인접 플레이어 누구도 (고용 준법 SaaS + 환급 트랜잭션 + 자체 인증)을 동시에 갖지 못한다 [추정, 본 조사·핸드오프 4사 조사 근거].
5. **권고: 진입 매력도 = 매력적(GO).** 단 "category-creation" 리스크를 PoC에서 의도적으로 디리스킹한다(손실회피 ROI 증명 + 행정사 제휴로 신뢰 빌림). go/no-go 워치 트리거 6종을 분기 모니터링한다.

## 3. 경쟁 포지셔닝 종합 (research-report)

### 3.1 2×2 — 누구도 "채용 이후 × E계열 기업 준법 원장"에 없다

```
                 채용 이후·상시 준법관리 (높음)
                           │
   행정사·노무사·대행기관   │   ★ VisaDesk (목표 공백 = 빈칸)
   (사람, 사후·건별)        │       — SaaS·상시·데이터·자동알림
                           │       + BackWon 환급 결합
 ──────채용 입구───────────┼───────────채용 이후·운영──────────
                           │
   Jobploy / KOWORK /       │   Hirevisa · vivisa
   MyKoreaWork              │   (상시관리 SaaS이나 D계열·대학)
   (채용+비자체크)          │
                           │
                 채용 이전·단발 (낮음)
        ↑ 기업(E계열) 축          대학·유학생(D계열) 축 →
```

- **세로축(채용 이후 상시 준법) × 가로축(E계열 고용기업)** 사분면 = **현재 빈칸**. Hirevisa/vivisa는 같은 세로 높이지만 D계열·대학 축에 있음 → **축이 다르다(우리의 right-to-win)**. 행정사·대행기관은 같은 세로 높이지만 "사람·건별"이라 SaaS·상시·데이터 자동화 공백이 그대로 남는다.

### 3.2 right-to-win (PlugNX가 왜 이기나 — 4 근거)

| 근거 | 내용 | 경쟁사 대비 |
|---|---|---|
| **R1 양면 데이터 결합** | 고용 B2B 준법 원장 × 근로자 환급/금융 B2C 결과를 **한 파이프라인**으로. 플라이휠: 기업 등록→근로자 BackWon 자동유입(전환 60%+·CAC 0 [SSOT])→근속률↑→B2B 유지 | 인접 누구도 (준법 SaaS + 환급 트랜잭션 + 자체 인증) 동시 미보유 [추정] |
| **R2 축의 차별화** | E계열×고용기업×채용이후 = 미점유 사분면 | Hirevisa·vivisa는 D계열×대학, Jobploy·KOWORK는 채용입구 |

## 4. vivisa×클링커즈(glow) 신용스코어 길목 — 속도전 함의

**팩트(라벨):** MOU **2025.12.18 체결**(언론 보도 12.19~12.23) [출처:서울경제 2025-12-19·벤처스퀘어]. 내용 = 클링커즈의 외국인 행동 데이터 + vivisa(예스퓨처)의 비자·행정 데이터를 결합한 **외국인 특화 대체신용평가 모델(ACSS)** 개발 + 소액 신용대출·BNPL(후불결제) + 입국 전(온보딩) 금융서비스 패키지. **추진방식 "단계적", 런치일·구체 모델 스펙·트랙션 수치 전무** [출처:벤처스퀘어·서울경제].

**우리 thesis와의 충돌·우위:**
- **충돌:** 그들의 "데이터→대체신용(ACSS)" 방향은 PlugNX ForeignID/고용데이터 기반 외국인 신용스코어 thesis와 **동일 길목** [추정].
- **그러나 데이터 입구가 다르다:** 그들 = **유학생(D계열) 학업·비자 + 생활 행동 데이터**. 우리 = **고용기업의 근로(E계열) 임금·재직·체류 데이터**. **신용평가에서 근로·소득 데이터가 학업·행동 데이터보다 예측력↑** [추정] → 입구 자체로 우리가 유리.
- **속도 판정:** **현재 위협 낮음**(MOU·단계적·런치 미정). 우리가 8주 PoC에서 ForeignID L2/L3 + 고용·임금 데이터를 **즉시 축적 시작**하면(이미 PoC 온보딩 흐름과 일치) **데이터 선점 우위**. 단 그들이 **Pre-A 펀딩 + 신용평가 제품(ACSS) 실출시**를 하면 길목 경쟁 본격화 → 분기 워치(트리거 W3).

**속도전 액션(80/20):**
1. PoC 온보딩 순간부터 고용·임금·체류·인증(L2+) 데이터를 **신용피처 전환 가능한 스키마로 정규 축적**.
2. "고용 데이터 = 외국인 대체신용의 더 강한 입구"를 IR·파트너십 내러티브로 선점.
3. 클링커즈/vivisa의 ACSS 제품 출시·펀딩을 트리거로 등록(아래 §5).

- 가격(Hirevisa·vivisa·Jobploy·대행 수수료)은 다수 **비공개 → "확인 필요"**. 가격 비교가 필요한 의사결정 전 1차 영업·공개자료 재확인 요망.
- vivisa×클링커즈 신용평가 모델(ACSS)은 **MOU 단계·런치 미정**으로, "출시"가 아닌 "계획" 상태임을 유지하고 분기 재검증한다.
- 민감정보(여권번호·외국인등록번호·계좌·생체)는 예시·로그에 실제 값을 남기지 않으며, 데이터 축적 시 목적·동의·보관기간·암호화·파기정책을 사전 정의한다.
