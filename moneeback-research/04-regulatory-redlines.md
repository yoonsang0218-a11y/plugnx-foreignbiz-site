# WS4 — 규제·자격사법·금융·개인정보 레드라인 (제로베이스 재검증)

> 작성 2026-06-29 KST · regulatory-risk 워크스트림 · 제로베이스 재검증(기존 자료=검증대상 가설)
> 면책: **참고용·법적 효력 없음.** 모든 판정은 행정사·노무사·세무사·변호사·금융규제 전문가 검증 + 최신 법령 확인 필요.
> 라벨: `[1차]`정부·공공·법원 / `[2차]`언론·연구 / `[해외]`해외사례 / `[추정]`가공치 / `[확인필요]`1차 미확정.

## 0. BLUF — 결론 먼저

**판정: 제품 경계만 정확히 그으면 4개 환급영역 "안내·연결·서류준비 지원"은 합법 통합 가능. 단 기존 분석은 두 곳에서 틀렸고(하나는 과대, 하나는 과소), '대행 vs 안내' 이분법보다 더 미세한 선이 진짜 레드라인이다.**

1. **기존 가설 "퇴직금·체불 대행=전부 노무사 독점, 행정사 수행=처벌" → 부분 오류(과대 위험).** `[1차/법원]` 2024년 판례(서울남부지법 2024고정678)는 행정사가 임금체불 **진정서 작성·노동청 제출**한 행위를 **무죄**로 봤다. 행정사법 §2가 공인노무사법의 "다른 법률에 따라 허용되는 경우" 예외에 해당하기 때문. → **행정기관 제출용 서류 작성·제출은 행정사 합법 영역**. 처벌은 그 너머(사업장 상대 내용증명 지급요청·분쟁 대리 38건 = 2020고단4087 유죄)에서 시작된다. 경계가 "퇴직금이냐"가 아니라 "**대(對)행정기관 서류작성**이냐 **대(對)사용자 청구·분쟁대리**냐"로 이동.

2. **기존 가설 "세무사법 §20③ 표현만으로 처벌" → 정확하나, 시점이 결정적으로 악화(과소평가).** `[1차/2차]` 세무대리 **오인 표시·광고**까지 금지하는 개정 세무사법이 **2026년 6월 시행**(바로 이번 달, 1년↓징역/1천만원↓벌금). '환급액 도착' 푸시 같은 Moneeback류 알림이 직격 대상. **"세금환급"은 4기둥 중 가장 위험한 칸** — 자체 수행 불가, 세무대리인(세무사) 제휴·연결로만.

3. **금융 풀스택(송금·대출·신용스코어)은 전부 별도 인허가 영역.** 직접 취급 시 무등록 영업으로 형사처벌. → Moneeback은 **자기가 금융업을 하지 말고**, 등록 사업자(은행·송금업자·대출모집법인·CB)에 **동의 기반 연결·송객**하거나 **마이데이터 신호 API**로 가야 합법.

4. **"외국인 신용스코어 제공"은 명칭·표현에 따라 무허가 신용평가업 리스크.** `[1차/공공]` 비금융정보만으로 점수를 매기는 **전문개인신용평가업은 신용정보법상 허가업(자본금 50억 기반)**. → 점수·등급을 직접 부여·판매하면 무허가. **"리포트/신호/데이터 API"** 로 표현하고 점수화는 허가받은 CB에 위임.

5. **개인정보·민감정보는 동의 기반 전송요구권으로 합법 경로 존재.** `[1차]` 신용정보법 §33-2 전송요구권은 **외국인등록번호 보유 외국인도 대상**(공공 마이데이터 명시). 단 외국인등록번호·여권은 고유식별정보 → **별도 명시 동의·분리보관·암호화 필수**.

**한 줄**: *"Moneeback의 합법성은 '대행을 안 한다'가 아니라 '각 칸마다 누가 등록·자격 보유자인지'를 정확히 라우팅하느냐에 달렸다. 환급 4칸은 합법 통합 가능, 단 세무는 2026.6 시행법으로 칸 자체가 좁아졌고, 금융 3칸은 전부 남의 라이선스 위에 얹어야 한다."*

## 1. 자격사법 4종 — 환급 4영역 통합 가능성 재검증

### 1.1 행정사법 — 서류작성·제출대행 `[1차]`
- **근거**: 행정사법 §2(업무: 행정기관 제출 서류 작성·제출 대행 등), §3(자격자만 업으로 수행), 벌칙 — 미등록자가 §2 업무 수행 시 **3년↓징역 또는 3천만원↓벌금**(기존 자료 "5백만원"은 오기 의심 → **확인필요**, 다수 출처 3천만원). 출처: [행정사법 본문](https://www.law.go.kr/lsInfoP.do?lsiSeq=180342)
- **재검증 결과**: 외국인 환급은 상당부분 **행정기관(공단·EPS·고용센터)에 본인 명의 서류 제출** → 행정사 영역과 본인 직접청구 영역. Moneeback이 비자격으로 **남의 서류를 작성·대리제출**하면 위법. **다국어 서류 가이드·본인 작성 지원·자기 정보 입력 도우미**는 가능(본인이 작성/제출 주체).

### 1.2 공인노무사 독점 — 퇴직금·체불임금 (★기존 분석 수정) `[1차/법원]`
- **근거**: 공인노무사법 §2(직무: 노동관계법령에 따른 신고·신청·청구·권리구제 대행/대리), 무자격 수행 처벌. 단 **"다른 법률에 따라 허용되는 경우" 예외** 존재. 출처: [공인노무사법](https://law.go.kr/LSW/lsInfoP.do?lsiSeq=154051)
- **★재검증 — 기존 "행정사 수행=처벌" 단정은 과대**:
  - `[1차/무죄]` **서울남부지법 2024고정678**: 행정사가 임금체불(연차·주휴수당) **진정서 작성→노동청 제출**, 수임료 약정 → **무죄**. 법원: 행정사법 §2가 공인노무사법의 "다른 법률 허용" 예외에 해당. ([로앤비/법률신문](https://www.lawtimes.co.kr/news/207558))
  - `[1차/유죄]` **2020고단4087**: 행정사가 임금체불 사건 수행하며 **사업장에 내용증명 지급요청** 등 노무사 직무 **38건** → 공인노무사법·변호사법 위반 **유죄**.
  - `[1차/무죄]` 수원지법 2022나92278: 행정사의 **근로복지공단 요양급여(산재) 신청 대리** + 성공보수 약정 유효 인정.
- **수정된 레드라인**: 경계는 "퇴직금이냐"가 아니라 **① 대(對)행정기관 서류작성·제출(행정사 가능) vs ② 대(對)사용자 직접 청구·교섭·분쟁대리(노무사/변호사 독점)**. Moneeback은 ①영역은 행정사 제휴로, ②영역은 노무사/변호사 라우팅으로. **플랫폼 자신은 어느 쪽도 직접 대리 금지.**

### 1.3 세무사법 §20③ — 표현·광고만으로 처벌 (★시점 악화) `[1차/2차]`
- **근거**: 개정 세무사법 — 무자격자가 세무대리를 **취급하는 것으로 오인될 우려가 있는 표시·광고**까지 금지, 위반 시 **1년↓징역 또는 1천만원↓벌금**. 출처: [INTN](https://www.intn.co.kr/news/articleView.html?idxno=2047607) [세무사법(law.go.kr)](https://law.go.kr/LSW/lsRvsDocListP.do?lsId=000639)
- **★재검증 — 시점이 결정적**: `[2차]` 개정안 **2025.12 개정 → 2026.6 시행**(=이번 달). 세무사회가 6월부터 플랫폼 제재 본격화 예고. ([taxwatch](https://www.taxwatch.co.kr/article/tax/2026/01/28/0003))
- **실제 처벌 선례**: `[1차/행정]` 삼쩜삼(자비스앤빌런즈) — 공정위, 표시광고법 위반 **과징금 7,100만원+시정명령**(2023.12). '환급액 도착''환급 대상 선정' 류가 거짓·오인 광고.
- **금지 문구**(직접 적용): "세금환급" "세금신고 대행" "절세전문" "기장대행", '세무사/세무대리/세무법인' 명칭·유사표현, '환급액 도착/조회대상 선정' 류 푸시.
- **결론**: **4기둥 중 세금환급이 최고위험 칸.** Moneeback 자체로 세금환급은 **표현조차 금지**. → 세무사·세무법인 **제휴·연결**로만, 화면문구는 "전문 세무대리인 연결". 연말정산 등은 "본인 직접 신고 안내·홈택스 핸드오프".

### 1.4 변호사법 §109 — 비변호사 법률사무 `[1차]`
- **근거**: 비변호사가 금품 받고 법률사건의 감정·대리·중재·화해·법률상담·법률문서 작성·알선 → **7년↓징역 또는 5천만원↓벌금**(4종 중 최고형). 출처: [변호사법 §109](https://www.law.go.kr/법령/변호사법/제109조)
- **재검증**: 환급분쟁·체불소송·민원의 **법률상담·대리·알선**을 플랫폼이 직접/유상 알선하면 직격. **단순 정보제공·자격자 단순 연결(유상 알선 아님)**은 경계 안. → 변호사 연결은 **광고/알선 수수료 구조를 변호사법 §34(알선·소개 대가 수수 금지)까지 함께 검토** 필요(★확인필요).

## 2. 금융 규제 — B2C 풀스택의 진짜 벽

### 2.1 송금 — 외국환거래법 소액해외송금업 / 전자금융거래법 `[1차/2차]`
- **소액해외송금업 등록 요건**: `[2차]` 상법상 회사 + **자기자본 10억원 이상**(개정 논의 20억), 외환정보집중기관 전산연결, 전산설비·전문인력, 외국환업무 2년경력자 2명↑. 출처: [외국환거래법 §15-2(law.go.kr)](https://www.law.go.kr/LSW//lsLawLinkInfo.do?lsJoLnkSeq=1000619563) [벤처스퀘어](https://www.venturesquare.net/1004023)
- **선불·이체 직접취급**: `[1차]` 전자금융거래법 — 미등록 선불전자지급수단 발행·관리 시 **3년↓징역 또는 2천만원↓벌금**. 출처: [전자금융거래법(law.go.kr)](https://law.go.kr/LSW/lsEfInfoP.do?lsiSeq=167420)
- **결론**: Moneeback이 송금/지갑/충전을 **직접** 하면 무등록 영업. → **등록 송금업자·은행 비교·연결(송객)** 또는 제휴 라벨. "송금 직접 취급"으로 오인되는 UI/문구 금지.

### 2.2 대출중개 — 금융소비자보호법 대출성상품 판매대리·중개업 `[1차/2차]`
- **근거**: `[2차]` 대출모집인 = 금소법상 **금융상품판매대리·중개업자 등록 필수**(금감원/협회). 미등록 영업 **5년↓징역 또는 2억원↓벌금**. **금소법 §22①: 판매업자 외의 자는 금융상품 광고 불가**. 출처: [FSC 보도자료](https://www.fsc.go.kr/no010101/77178) [금소법(law.go.kr)](https://www.law.go.kr/LSW/lsInfoP.do?lsId=013704)
- **결론**: "대출 승인 보장" 절대 금지(허위·오인). 대출중개는 **등록 대출모집법인 제휴 또는 자체 등록** 없이는 광고조차 위험. → 등록 파트너 연결·송객 구조로.

### 2.3 외국인 신용스코어 — 무허가 신용평가업 리스크 (★핵심) `[1차/공공]`
- **근거**: `[공공]` 비금융정보만 처리하는 **전문개인신용평가업**은 신용정보법상 **허가업**(개인신용평가업 자본금 50억↑ 기반, 처리정보 범위별 차등). 출처: [마이데이터플랫폼 CB 허가안내](https://www.mydataplatform.or.kr/cb/cb.jsp) [FSC 개인신용평가체계 개선방안](https://www.fsc.go.kr/comm/getFile?srvcId=BBSTY1&upperNo=73008&fileTy=ATTACH&fileNo=6)
- **★재검증**: "고용·임금 데이터로 외국인 **신용스코어** 제공"을 **점수/등급 직접 부여·판매**하면 **무허가 신용평가업** 소지. 경쟁 vivisa×클링커즈의 "비자데이터→대체신용평가"도 동일 규제 직면(WS3 워치).
- **합법 경계**: ① **점수화는 허가 CB(나이스·KCB 등)에 위임**, Moneeback은 동의 기반 **원천 신호(재직·임금·체류 검증 결과) 데이터 API 제공**(raw DB 판매 아님, 동의기반 신호/리포트) ② 자체로는 "신용평가/신용점수/등급" 표현 회피, **"금융 준비도 리포트""거래이력 정리"**로. ③ 향후 본격화 시 전문개인신용평가업 허가 또는 제휴.

### 2.4 AML/KYC — 특정금융정보법 `[1차]`
- L3 금융거래·송금 연계 시 고객확인(CDD/EDD)·STR·제재대상 스크리닝 의무가 **연계 금융사** 측에 발생. Moneeback이 직접 금융업 미수행이면 직접 의무는 낮으나, **본인인증(ForeignID) 결과를 금융사 KYC에 제공**하는 구조라면 데이터 정확성·위탁계약 책임 발생. 운영기준 FIU **최신 확인**.

## 3. 개인정보보호법 — 민감·고유식별정보와 동의 기반 조회위임

- **외국인등록번호·여권번호 = 고유식별정보(준)**: `[1차]` 처리에 **별도 명시 동의 + 안전성 확보조치(암호화·접근통제·감사로그) + 분리보관**. 예시·로그에 평문 금지(마스킹). 출처: [개인정보보호위 pipc.go.kr]
- **동의 기반 공단/보험사 가입내역 조회위임 — 가능성 있음**: `[1차]` 신용정보법 §33-2 **전송요구권**으로 본인이 본인정보를 본인/마이데이터사업자에게 전송요구 가능. **외국인등록번호 보유 외국인도 대상**(공공 마이데이터 명시). 출처: [전송요구권 가이드](https://inpyeonglaw.com/archives/25736/) [공공마이데이터 가이드 2025.08](https://adm.mydata.go.kr/images/guide.pdf)
  - **단**: ⓐ 마이데이터(본인신용정보관리업)로 직접 하려면 **허가 필요** ⓑ 비허가 상태에선 **본인이 직접 조회→결과를 본인이 입력/업로드**하는 구조(전송요구의 수령자=본인)거나, **허가 마이데이터사업자와 제휴**해야 함 ⓒ 공단·보험사가 전송 대상기관인지(연금·보험 데이터의 마이데이터 편입 범위)는 **★확인필요**.
- **목적 제한·최소수집**: VisaDesk(B2B)↔Moneeback(B2C) 데이터 공유는 **동의 범위·목적 내**에서만. 플라이휠 전제인 "기업이 등록한 근로자 정보의 B2C 활용"은 **근로자 본인 동의 분리 획득**이 전제(B2B 고객 동의로 갈음 불가).

## 4. 안전한 제품 경계 · 금지표현 · 수익구조

### 4.1 Green(합법) / Amber(전문가검토 후 제한적) / Red(금지)

**Green — 운영보조·정보제공·동의기반 연결**
- 환급 가능성 **진단·교육 콘텐츠**(다국어), 본인 직접청구용 **서류 가이드·체크리스트**
- ForeignID 동의 기반 **자격자/공식채널 라우팅·핸드오프**(공단 1355·EPS·세무사·노무사·행정사)
- 동의 기반 **본인 데이터 정리·리포트**("금융 준비도/거래이력 리포트")
- 등록 금융사(은행·송금업자·대출모집법인·CB)와의 **제휴·송객 연결**

**Amber — 전문가/제휴/등록 전제로만**
- 행정기관 제출 서류 작성·제출 → **행정사 제휴** 하에 (대행정기관 한정)
- 신용 신호 데이터 → **허가 CB 위임**(점수화는 CB)
- 마이데이터식 가입내역 조회 → **본인 수령 구조 or 허가 마이데이터 제휴**
- 변호사·노무사 연결 → **알선 대가 수수 구조 적법성 검토(변호사법 §34 등)**

**Red — 즉시 제거**
- "환급 대행" "우리가 받아드립니다" "세금환급/신고대행" 표현
- '환급액 도착''조회 대상 선정' 류 미확정 환급 푸시(표시광고법+세무사법)
- "대출 승인 보장", 비등록 대출 광고
- 플랫폼이 직접 부여하는 "신용점수/신용등급/신용평가"
- 송금·지갑·충전 직접 취급(무등록)
- 비자격 서류 작성·대리제출, 사용자 상대 직접 청구·분쟁대리

### 4.2 금지표현 → 안전한 대체 (핵심 매핑)
| 금지(Red) | 안전 대체(Green) | 근거 |
|---|---|---|
| 환급 대행해 드립니다 | 받을 수 있는 환급 **안내·서류준비 지원·전문가 연결** | 행정사법·노무사·세무사법 |
| 세금 환급/신고 대행 | **세무 전문가(세무사) 연결** / 홈택스 본인신고 안내 | 세무사법 §20③(2026.6) |
| 당신의 신용점수는 N점 | **금융 준비도 리포트**(점수는 제휴 CB) | 신용정보법 신용평가업 허가 |
| 대출 승인 보장 | 등록 파트너 **대출상품 비교·연결** | 금소법 §22 |
| 송금해 드립니다 | 등록 송금업자 **비교·연결** | 외국환거래법·전금법 |

### 4.3 수익구조 합법성
- **합법**: 구독료(B2B SaaS), 자격사/금융사 **제휴 중개·송객 수수료**(단 변호사 알선 대가는 §34 검토), 데이터 API(동의기반 신호, raw DB 판매 아님).
- **위험**: 환급 **성공보수 직접 차감**(자격사 제휴 없이) — 자격사법 위반. 변호사 사건 알선 대가 — 변호사법 §34.
- **권고**: 환급은 **무료 유입·동의 획득 훅**, 수익은 ① B2B 구독 ② 적법 금융 송객 ③ 동의기반 데이터 API로.

## 5. De-risking — 확인필요 1차 출처 체크리스트 & go/no-go

### 5.1 즉시 확인필요(제품화·인용 전)
1. `[확인필요]` 행정사법 벌칙 정확값(3년/3천만원 vs 5백만원 오기) — [행정사법 본문](https://www.law.go.kr/lsInfoP.do?lsiSeq=180342) 조문 직접.
2. `[확인필요]` 개정 세무사법 §20③ **정확 시행일·금지 표현 범위 최종본** — 법제처 [세무사법](https://law.go.kr/LSW/lsRvsDocListP.do?lsId=000639) 부칙.
3. `[확인필요]` 연금·보험 데이터가 **마이데이터 전송 대상**인지(전송요구권 수신기관 범위) — 금융위/마이데이터지원센터.
4. `[확인필요]` 변호사법 §34(알선 대가 수수) 하에서 변호사 연결 수익구조 적법성.
5. `[확인필요]` 전문개인신용평가업 허가 자본금·요건 최신값 — [신용정보업감독규정](https://www.law.go.kr/행정규칙/신용정보업감독규정).
6. `[확인필요]` 소액해외송금업 자기자본 현행(10억 vs 20억 개정) — 기재부 고시.

### 5.2 go/no-go 게이트
- **GO**: 4기둥 모두 "진단→자격자/등록사 라우팅" 오케스트레이션으로 재설계 + 위 1·2 시행법 확인 + 금지표현 카피 전수 점검 통과.
- **CONDITIONAL**: 세금환급 칸은 2026.6법 리스크로 **세무사 제휴 확정 전까지 비활성**(표현조차 노출 금지). 신용스코어는 CB 제휴/허가 전까지 "리포트"로만.
- **NO-GO(특정 기능)**: 송금·지갑·신용점수 직접 취급, 환급 직접 대행 — 등록·제휴 없이는 출시 불가.
