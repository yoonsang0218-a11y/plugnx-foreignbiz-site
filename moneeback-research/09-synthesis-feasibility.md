## 0. BLUF — 종합 결론

**판정: 조건부 GO. 단 기존(2026-06-26) "조건부 GO"와 결론 단어는 같으나 내용은 더 비관·더 정밀해졌다.** 제로베이스 8축 재검증 결과, BackWon의 사업 정당화 근거는 "환급 사업"에서 **"VisaDesk(B2B)가 깐 데이터·채널 위에 얹는 동의획득 훅 + 외국인 금융 데이터 레이어"**로 더 강하게 이동해야 한다. 8개 WS가 독립적으로 같은 곳에 수렴했다: **환급은 매출원이 아니라 입구이고, 단위경제의 생사는 "금융연계 attach율(가정 15%)" 단 하나에 달려 있다.**

세 가지가 기존 대비 명확히 바뀌었다:
1. **환급 단독 P&L은 숫자로 NO가 확정됐다(WS7).** 1인 평균 반환일시금 870만원[1차], 정부 무료채널(인천공항 출국장·국세청 원클릭)이 상단을 메우고, 자격사법이 고마진 직접과금을 막아, 합법 과금 가능 매출은 **건당 0~25만원·공헌이익 0~10만원**. B2C 단독은 전 시나리오 적자. 기존 ARPU 140만 가정은 과대.
2. **right-to-win의 진짜 전장은 "환급을 더 잘함"이 아니라 "외국인 고용·임금 신호의 B2B 데이터 공급"(WS3·WS6)이다.** 그런데 이 핵심 수익원(신호 라이선스)의 **신용정보법 적격성·은행/CB 지불단가는 둘 다 미입증(partially)**이다. 즉 가장 큰 업사이드가 가장 큰 미해결 리스크와 같은 칸에 있다.
3. **정책이 미는 방향(정주화 E-9→E-7-4)과 환급 수익원(출국)이 반대로 간다(WS2·WS5).** 숙련전환 성공 = F/E-7 = 반환일시금 자격 소멸 = 출국 트리거 감소. 정책 순풍이 환급 코어를 갉는다. → 무게중심을 재직 중 금융연계로 옮기는 것이 불가피.

**한 줄**: *"BackWon은 '환급 스타트업'으로 보면 NO, 'VisaDesk가 CAC 0으로 모은 외국인 모수 위에 동의·데이터를 쌓아 금융사에 신호를 파는 데이터 레이어'로 보면 조건부 GO. GO의 모든 조건은 ⓐ금융 attach·신호 라이선스 적격성, ⓑNPS·보험 데이터 접근(마이데이터 편입), ⓒ자격사 제휴 공급, ⓓ교차판정 정확성 — 이 4개의 미해결 게이트 통과 여부에 달렸다."*

## 3. SWOT

**Strengths**
- VisaDesk B2B 유입 = 한계 CAC 0 (4사·송금사·NICE 모두 못 가진 채널 우위)[SSOT/검증]
- 다수 고용주에 걸친 검증된 국내 고용·재직·임금 데이터 = 경쟁자(본국CB·통신·유학·자행급여)가 못 가진 입력값
- 페인 1차 확인(미청구 1,138억·체불 2배·정보비대칭)·교차판정 정확성이 신뢰 코어
- 양면 역연결(체불 신호→VisaDesk 준법) = 단독 스타트업 복제 불가 구조

**Weaknesses**
- 환급 1회성·저공헌(0~10만)·정부 무료채널 잠식 → 단독 단위경제 적자
- 핵심 수익원(신호 라이선스)의 신용정보법 적격성·지불단가 미입증
- 6개 언어 CS·KYC 운영비는 0이 아님 → CAC 0이어도 공헌 작으면 흑자 미미
- B2B 역연결 이해상충(기업이 자사 근로자 체불 적발 SaaS를 기피할 위험)

**Opportunities**
- 반환일시금 지급 4배 급증(869억'19→3,597억'24)[1차/2차] = 출국정산 흐름 모수 폭증
- 연금 보험료율 매년 인상(→13%/2033)[1차] = 급여공제 진단 타이밍 매년 강화
- ICAO 표준·모바일 등록증 금융활용[1차] = ForeignID eKYC 정합
- 은행·CB의 외국인 대안신용 도입 의지 실재(KB-EQUAL·케이뱅크·신한 SOL글로벌론 "급여 3개월")[1차/2차] = 데이터 수요 신호

**Threats**
- 세무사법 §20③ 2026.6.24 시행[1차 확인] = 세금 칸 표현 리스크(주체·맥락 조건부, 옐로)
- 한패스(송금 3조·MAU 40만·2026.2 대출비교·대안신용)·NICE Welko('26.6.9)·vivisa×glow = R3 길목 선점 경쟁
- 정주화 정책 = 출국 트리거·반환일시금 자격 감소(수익원 잠식)
- NPS·출국만기보험 데이터가 마이데이터 전송대상에 미편입 시 핵심 UX("당신 환급액 표시") 법적 불가[확인필요]

## 5. GO 조건 (조건부GO 충족조건)

1. **포지셔닝 재정의 확정**: "환급 대행 사업"→"외국인 금융 입구(환급=동의획득 미끼, 수익=금융 신호·송객+B2B 구독)". IR·SSOT에서 환급 ARR을 "환급 1~3억 + 금융 attach 옵션"으로 분리 표기.
2. **금융 attach 파일럿 통과**: 송금 1개 제휴로 환급조회 유저 attach ≥10% 실측(WS7 게이트).
3. **신호 라이선스 적격성 법률검토 통과**: 동의기반 고용·임금 신호 제공이 신용평가업 본허가 불요로 합법(점수 자체 산출 금지) + 은행/CB 1곳 유료 PoC 의향.
4. **데이터 접근 게이트(ⓔ)**: NPS·출국만기보험의 마이데이터 전송대상 편입 여부 확인. 미편입 시 본인 직접조회 대체 플로우로라도 핵심 UX 성립 확인.
5. **자격사 제휴 공급 확보**: 세무사·노무사·행정사·등록 금융사 중 환급 4칸 라우팅에 필요한 제휴 RFI 1차 합의.
6. **교차판정 정확성**: 비자×국적×가입여부×국가별 최소기간 다축 엔진 + NPS 런타임 조회. 단일 카피 마케팅 금지.
7. **규제 카피 전수 점검**: 세무사법(2026.6.24)·자격사법·금소법·신용정보법 레드라인 통과.

## 6. Kill Criteria (이러면 접는다)

1. **금융 attach <5%** (파일럿) 그리고 신호 라이선스 적격성 부정 → BackWon 독립 BM 폐기, VisaDesk 무료 부가기능으로만 잔존.
2. **신호 라이선스가 신용평가업 본허가 대상으로 판정** 되고 은행·CB 지불의사 0 → 데이터 레이어 right-to-win 붕괴 = NO-GO.
3. **NPS·보험 데이터 마이데이터 미편입 + 본인 직접조회 전환율 붕괴** → 핵심 UX 불가, 환급 입구 가치 소멸.
4. **환급 실과금전환 <5% + R3 한패스/NICE에 완전 선점** → 입구 가치·데이터 선점 둘 다 실패.
5. **자격사 제휴 전면 거부** → 합법 경계는 그려도 공급 없어 제품 빈 껍데기.
6. **B2B 역연결이 VisaDesk 도입을 실제로 위축**시킴이 PoC에서 확인 → 양면 플라이휠 핵심 가정 붕괴.

## 7. 디리스킹 실험 우선순위 (검증 순서)

> 원칙: 가장 큰 미해결 리스크(R1~R3)를 가장 싸게·가장 먼저. 법률검토·RFI는 코딩 전.

1. **[최우선] 신호 라이선스 적격성 법률검토** (신용정보법 §32·33, 본허가 불요 범위) — 통과 못하면 right-to-win 자체가 없으므로 1순위. 비용 낮음, 분기 효과 큼.
2. **NPS·출국만기보험 마이데이터 전송대상 편입 확인** (금융위/마이데이터지원센터 1차) — 핵심 UX·플라이휠 데이터 가설(ⓔ)의 선결.
3. **은행·CB RFI** (신한·하나·NICE·KCB): "국내 고용·임금 신호에 지불의사·단가" — 1곳 유료 PoC 의향이 데이터 BM go 기준.
4. **금융 attach 파일럿** (VisaDesk 관리외국인 + 송금 1개 제휴): 환급조회→송금 전환율 (게이트 ≥10%).
5. **자격사 제휴 RFI** (세무사·노무사·행정사·등록 금융사): 요율·합법성·외국인 저단가 1회성 수용 여부.
6. **환급 실과금전환 실측** (PoC 관리외국인 300명): 노출→가입→조회→실거래 깔때기 (게이트 ≥5%).
7. **교차판정·AI 진단 정확도 백테스트** (명세서 100건, 노무사 라벨 대비; 최저임금축 ≥95%, 수당축 ≥80%) + 오진 면책 UX 법률검토.
8. **반환일시금 1차 원자료 확정** (NPS 통계연보: 중국 지급 1위 메커니즘·국가목록 변동성) — 교차판정 엔진 파라미터 확정.
