# WS15 — Moneeback A-Z 하단 유저 커버 서비스 기획

> 작성 기준일: 2026-06-30 KST
> 요청: "하단 유저문제를 A-Z까지 전부 커버한다고 생각하고 서비스 기획"
> 사용 스킬: `foreign-opportunity-discovery` · `market-research` · `moneeback-refund` · `foreign-visa-kb`
> 핵심 관점: Moneeback은 외국인 재직자에게는 **무료 생활·정산·금융 준비 도우미**, 금융권/CB에는 **동의기반 신용 보강 리포트 인프라**다.
> 면책: 비자·노무·세무·법률·금융 판단은 법적 효력 없는 참고 정보다. 제품화 전 행정사·노무사·세무사·변호사·금융규제 전문가 검토와 최신 1차 출처 확인이 필요하다.

## 0. Answer First

**Moneeback은 "외국인 근로자의 한국 생활 운영체제"처럼 보여야 한다.** 하단 유저는 제도가 없어서 막히는 게 아니라, 제도가 너무 흩어져 있고 한국어·서류·시점·전문가 판단·금융 번역이 안 돼서 막힌다. 따라서 서비스는 A-Z를 커버하되, 모든 기능은 아래 하나의 목적에 복무해야 한다.

> **재직·소득·체류·보험·주거·정산 데이터를 본인 동의로 쌓아, 금융권이 조회 가능한 Foreign Worker Credit Enhancement Report로 전환한다.**

**제품 한 줄**

> Moneeback Passport: 외국인 재직자가 한국에서 일하고, 살고, 돈을 받고, 금융을 이용하고, 이직/전환/출국까지 준비하는 다국어 개인 운영 대장.

**핵심 원칙**

1. 유저에게는 **무료**가 기본이다. 돈을 받으면 하단 유저 데이터 축적이 줄어든다.
2. 정부/EPS/NPS/하이코리아와 **경쟁하지 않는다**. 공식 서비스로 보내되, 개인별 체크·서류·번역·알림·증빙화를 맡는다.
3. 전문가는 **레드플래그 라우팅**만 한다. 수임 성공보수/소개료를 주 수익모델로 잡지 않는다.
4. 수익은 **CB/은행/카드/보험/송금사의 건당 조회료·API료·PoC fee**에서 나온다.
5. 신용점수는 직접 만들지 않는다. **점수 없는 신호 리포트**를 만든다.

## 5. 서비스 운영 플로우

### 5.1 유저 플로우

```text
가입
→ 언어 선택
→ ForeignID 인증
→ 내 상태 입력
→ 오늘 해야 할 일 생성
→ 급여/재직/체류/보험 서류 업로드
→ 무료 체크 결과 제공
→ 부족 서류 안내
→ 금융 준비도 리포트 생성
→ 금융권 제공 동의
→ 공식기관/전문가/금융사 라우팅
→ 매월 업데이트 리마인드
```

### 5.2 레드플래그 라우팅

| 레드플래그 | 기본 처리 | 전문가/기관 라우팅 |
|---|---|---|
| 체류만기 30일 이내 | 하이코리아/출입국 방문예약 안내 | 행정사/출입국 상담 |
| 임금 2개월 이상 지연 | 증빙 패키지 생성 | 노동청/노무사 |
| 산재 의심 | 사고 기록·병원 자료 체크 | 근로복지공단/노무사 |
| 세금/연말정산 복잡 | 홈택스 공식 안내 | 세무사 |
| 고액 보증금 분쟁 | 계약서 보관·위험 안내 | 변호사/법률구조 |
| 출국 D-30 | EPS/NPS/보험 체크리스트 | 보험사/NPS/노무사 |

### 5.3 전문가 연결 원칙

| 원칙 | 설명 |
|---|---|
| 수임대가 쉐어 금지 | 변호사·세무사 등은 소개/알선 대가 금지 리스크가 큼 |
| 디렉토리·광고형 우선 | 유저가 선택, 광고 표시, 수임 여부와 무관한 정액 과금 |
| 전문가용 SaaS 가능 | intake, 번역, 서류관리, 예약 도구 월정액 |
| 본인 주도 문서 | Moneeback은 본인 입력/보관/출력 도구, 대리 작성/제출 아님 |
| 상담 전 패키지 | 유저가 전문가에게 직접 전달하는 증빙 묶음 |

## 6. 제품 패키지

### 6.1 Free: Survival Passport

대상: 모든 외국인 재직자

기능:
- 언어 선택
- 체류만기/주소/여권 알림
- 급여명세서 월렛
- 보험/환급 체크리스트
- 출국정산 체크
- 공식기관 링크
- 기본 금융 준비도

목적:
- 유저 획득
- L1/L2 인증
- 기본 증빙 3종 확보

### 6.2 Plus: Financial Readiness

대상: 금융상품을 원하거나 증빙을 자주 쓰는 재직자

기능:
- 재직·소득 패키지 PDF
- 월별 급여 안정성 리포트
- 주소/월세/보험 증빙 패키지
- 금융권 제출용 readiness report
- 부족 서류 추천

수익:
- 유저 과금은 낮게 또는 무료 유지
- 금융권 조회료를 우선

### 6.3 Partner: CB/Bank API

대상: CB, 은행, 카드사, 송금사, 대출모집법인

기능:
- 본인 동의 기반 리포트 조회
- 원천증빙 최신성
- missing docs flags
- 체류/재직/소득/보험 신호
- API 또는 리포트 링크

수익:
- 건당 조회료
- 월정액 API
- PoC fee

### 6.4 Expert Workspace

대상: 노무사, 세무사, 행정사, 변호사

기능:
- 상담 전 intake
- 다국어 요약
- 증빙 패키지
- 예약/상태관리

수익:
- 수임 성과와 무관한 SaaS 월정액
- 광고/디렉토리 정액

## 7. MVP 범위

### 7.1 8주 MVP

| 주차 | 범위 | 산출 |
|---|---|---|
| 1~2 | 언어/인증/동의 | ForeignID L1, 언어 선택, 동의센터 |
| 2~3 | 내 상태 대시보드 | 비자·직장·급여·보험·주소 카드 |
| 3~4 | 급여·재직 월렛 | 계약서/급여명세/입금내역 업로드 |
| 4~5 | 환급·보험 체크 | NPS/EPS/보험 공식 라우팅 |
| 5~6 | 금융 준비도 리포트 | 점수 없는 readiness report |
| 6~7 | 전문가/기관 라우팅 | 레드플래그별 공식기관/전문가 안내 |
| 7~8 | 파일럿 | 유저 100명, 금융권 2곳 RFI |

### 7.2 MVP에서 빼야 할 것

- 직접 대출중개
- 직접 송금/지갑
- 직접 신용점수/등급
- 세금환급/신고대행 표현
- 비자/노무/법률 대리
- 전문가 수임 성공보수 쉐어

## 11. 최종 제품 정의

**Moneeback A-Z는 아래 4개 제품의 묶음이다.**

1. **Passport**: 신원·체류·주소·언어·동의
2. **Money & Work Wallet**: 급여·재직·보험·주거·송금 증빙
3. **Readiness Report**: 금융권 제출용 점수 없는 신용 보강 리포트
4. **Help Router**: 공식기관·전문가·금융사 라우팅

**유저에게는 생존 도구, 금융권에는 데이터 인프라다.**
