## 0. BLUF — 결론 먼저

**정책 타이밍은 BackWon 편이다. 단, "환급(R1)"은 순풍 강함, "금융연계·외국인 신용스코어(R3)"는 길목이 이미 닫히기 시작했다(경쟁 진입). 결론: 환급+출국정산을 'Act now'로 먼저 깔고, 금융연계는 6~12개월 내 제휴로 들어가지 못하면 'Risk(선점 상실)'.**

3일 전 내부 분석의 핵심 결론("기조 전환이 BackWon과 정합")은 **재검증 결과 유지**되나, 한 가지를 **뒤집는다**:

- 내부 분석은 반환일시금 페인을 주로 **"미청구 1,138억"(누적 잔존)**으로 잡았다. 그러나 1차 재확인 결과 **실제 지급액이 2019년 869억 → 2024년 3,596억으로 4배 급증**([2차/국감 인용], 아래 §2.1). 즉 페인은 "잔존 미수령"보다 **"매년 폭증하는 출국 정산 이벤트 모수"**가 더 큰 그림이다. → BackWon 메시지를 "안 받고 나간 돈 되찾기(잔존)"에서 **"지금 나가는 사람의 출국 정산 내비게이션(흐름)"**으로 이동해야 한다.

- 내부 분석이 놓친 **결정적 역풍**: 한패스가 2026.2 외국인 전용 대출비교 + 송금·체류 데이터 기반 외국인 대안신용평가 모델을 발표([2차], §3.3). BackWon R3(금융연계/신용스코어)의 핵심 길목에 **이미 경쟁자가 진입**했다. "why now"가 R3에서는 "why late"가 될 위험.

판정 요약(MECE):

| 축 | 정책 타이밍 | 판정 |
|---|---|---|
| R1 환급·출국정산 | 반환일시금 지급 4배 급증 + 연금료율 인상 + 가사관리사 종료자 정산 수요 | **Act now (순풍 최강)** |
| 인프라(ForeignID) | 외국인 기본인적정보 ICAO 통일 시행 + 모바일 등록증 금융 활용 | **Act now (정합)** |
| R3 금융연계·신용스코어 | 대안신용 활성화 = 순풍이나 한패스 선점 = 역풍 | **Investigate→Risk (창 닫히는 중)** |
| 신규유입 모수 | E-9 13만→8만(−38.5%) | **Risk (보정 필요, 단 환급엔 영향 작음)** |

## 1. 기조 전환 검증 — "양적확대→수급안정·관리·신뢰"가 BackWon과 정합한가

### 1.1 1차 확인 — 기조 전환은 사실 (BackWon 정합 유지)

`[1차]` **법무부 「2030 이민정책 미래전략」(2026.3.3 발표)** — 5대 전략: ①해외 고급인재 유치 ②민생경제 활성화 ③안전한 국경관리 ④국민이 공감하는 사회통합 ⑤외국인 인권 보호. (출처: [정책브리핑 148960240](https://www.korea.kr/news/policyNewsView.do?newsId=148960240))
- 사회통합: 장기거주 외국인 **사회통합프로그램 의무화**, 입국 전 한국어 교육.
- 인권 보호: **(가칭)K-Trust 기업 체류·고용 인증제** — 성실기업에 체류연장 자동승인 등 인센티브. (PROJECT.md의 K-Trust 명칭·취지 원문 정합 확인됨. **단 운영 세부 요건·배점·혜택은 [확인필요].**)

`[1차]` **2026 비전문 외국인력 8만명 확정(외국인력정책위, 2025.12.22)** — "코로나 이후 일시 증가한 수요가 안정 국면, 제조·건설 빈일자리 감소"가 공식 사유. (출처: [정책브리핑 156736250](https://www.korea.kr/briefing/pressReleaseView.do?newsId=156736250), [KDI 275206](https://eiec.kdi.re.kr/policy/materialView.do?num=275206))

**해석**: 정부 스스로 "양적 확대 종료, 안정·관리" 기조를 명문화. BackWon의 "채용 이후를 붙드는 인프라" 테제는 **정책 무게중심과 정합**. 내부 분석 결론 유지.

### 1.2 냉정한 카운터 — "정합"이 "수요"는 아니다

기조 전환은 **VisaDesk(재직·전환·정주 관리)**에 직접 순풍이지만, **BackWon(환급)에는 간접적**이다. "관리·신뢰 강화"는 기업·정부의 관리 도구 수요이지, 근로자가 환급앱에 돈을 낼 이유를 직접 만들지는 않는다. BackWon의 진짜 정책 순풍은 기조 전환이 아니라 **§2의 개별 제도(반환일시금 급증·연금료율 인상·금융접근성)**다. 기조 전환을 BackWon IR의 주근거로 쓰면 논리 비약.

## 2. BackWon 직접 관련 정책 — 1차 재검증

### 2.1 국민연금 반환일시금 — 모수 4배 급증 (가장 큰 순풍, 그러나 내부 분석과 각도 다름)

`[2차/국감 인용, 1차 재확인 필요]` 외국인 반환일시금 **실제 지급액 추이**(2025 국정감사 자료 인용 보도):
- 2019년: **869억원 / 45,259명**
- 2024년: **3,596억원 / 41,094명** (← 5년 만에 약 4배)
- 2025년 상반기만: **약 1,979억원 / 21,454명**
- 국가별 비중 1위 **중국 23.4%**, 이어 필리핀·인도네시아·스리랑카·태국 등.
- (출처: [뉴스1 5955472](https://www.news1.kr/bio/welfare-medical/5955472), [네이트 재게재](https://news.nate.com/view/20251028n04945) — **국감 제출자료·국민연금공단 원자료로 1차 재확인 필요. 보도 내 국가 비중 표기에 일부 혼선 있어 원자료 우선.**)

**기회 번역**:
- 내부 분석은 "미청구 1,138억(잔존)"을 강조했으나, 더 큰 그림은 **"매년 4천억대 정산 이벤트가 실제로 발생 중"**이라는 흐름. → BackWon의 TAM 논리를 "잠자는 돈 발굴"에서 **"매년 발생하는 출국 정산 흐름에 올라타기"**로 전환하면 모수·빈도 근거가 훨씬 강해진다.
- 중요한 함정 보정: **반환일시금은 고용허가제(E-8/E-9/H-2) 국적 무관 지급**이나, **중국·베트남·몽골 등은 일반 반환일시금 비대상**(상호주의·협정국만)이라는 점은 내부 분석(§1.3)이 맞다. 위 통계에서 중국 비중이 높은 것은 **사회보장협정 또는 상호주의에 따른 지급분**으로 해석되며, **국적×비자×협정 3중 교차판정이 전환율·신뢰의 생명**이라는 결론은 강화된다. `[1차]` 사회보장협정 26개국 체결, 주요 송출국(필리핀·인니·미얀마·캄보디아·태국 등) 다수 미체결.

`[추정]` 1인당 평균 수령액 수백만~1천만원대 = "돈 낼 만큼 큰 문제" 하한 충족.

### 2.2 국민연금 보험료율 인상 — 출국정산·급여공제 진단 웨지 (확정 순풍)

`[1차]` **국민연금법 개정 2026.1.1 시행** — 보험료율 9%→매년 0.5%p씩 인상→**2033년 13%**. 소득대체율 41.5%→43%. (출처: [보건복지부 연금개혁 Q&A](https://www.mohw.go.kr/menu.es?mid=a10714060000), [국민연금 온에어](https://www.npsonair.kr/advantages/detail.html?strIdx=3769))

**기회 번역**: 외국인 가입자의 **월 공제액이 매년 증가** → "내 급여에서 얼마 떼이고, 나갈 때 얼마 돌려받나"의 정보비대칭이 커진다. BackWon "급여 공제 적정성 진단 + 출국 시 예상 반환액 자가진단"의 정책 타이밍이 매년 강화됨. **단 "예상액 확정" 표현 금지, "추정·공단 확인 필요" 라벨 필수.**

### 2.3 외국인 기본인적정보 ICAO 표준 통일 — ForeignID 정합 (확정 순풍)

`[1차]` 출입국관리법 개정(2024.11.28 국회 가결, **2025.6.21 시행**) — 외국인 기본인적정보를 ICAO 국제표준 영문성명 등으로 정의·범정부 통일. (출처: [정책브리핑 148919186](https://www.korea.kr/news/policyNewsView.do?newsId=148919186), [법무부 보도자료 PDF](https://www.corrections.go.kr/bbs/moj/182/475066/download.do))
- 추가 순풍: 모바일 외국인등록증 6개 은행 계좌개설(2025.3) + 진위확인 제2금융권 확대(2025.6). `[1차]`

**기회 번역**: ForeignID 데이터 스키마를 국가표준에 정렬 = eKYC·금융 온보딩의 길목. **단 "공식 진위확인 권한 보유"로 표현 금지(§4).**

### 2.4 신용정보법·대안신용·마이데이터 — 외국인 명시 여부는 [확인필요]

`[2차]` 금융권은 통신비·공과금 등 비금융 데이터 기반 대안신용평가(CSS)로 신파일러를 재평가 중. 카카오페이 마이데이터 기반 CSS가 주금공 전세대출보증에 적용. (출처: [디지털타임스](https://www.dt.co.kr/article/12063411))
`[확인필요]` **2026 신용정보법 개정에 "외국인/체류외국인"이 명시 대상으로 들어가는지 1차 미확정.** 금융위 신용평가체계 개편 TF는 개인·개인사업자·thin-file 중심이며 외국인 특정 조항은 공식 원문에서 확인 못함. → PROJECT.md의 "26 신정법 개정으로 외국인 대안신용 확대"는 **희망적 추정이며 [확인필요] 유지**.

## 3. 역풍 — 1차 재검증

### 3.1 E-9 13만→8만('26, −38.5%) — 환급 모수엔 영향 작음 (보정)

`[1차]` 2026 E-9 8만(제조 5만·농축산 1만·어업 7천·건설 2천·서비스 1천+탄력 1만), E-8 계절근로 **10.9만(전년 대비 +1.3만)**, 총 비전문 19.1만. (출처: [정책브리핑 156736250](https://www.korea.kr/briefing/pressReleaseView.do?newsId=156736250), [다음/연합 종합](https://v.daum.net/v/20251222192443212))

**번역**: 내부 분석대로 신규유입 둔화는 사실이나, **환급 모수에 미치는 영향은 제한적**이다 — ① 환급 대상은 신규 입국자가 아니라 **출국·재직 중인 기존 110만+ 재고(스톡)**, ② E-8 계절근로는 오히려 증가(+고회전 출국 트리거), ③ §2.1대로 반환일시금 지급은 오히려 4배 급증 중. → **"신규유입 둔화 = 환급 사업 축소"는 오독.** 신규유입 둔화가 타격하는 것은 B2C 신규 모객 깔때기(VisaDesk 신규 등록 유입)이지 환급 모수가 아니다.

**냉정한 카운터**: 단, 장기적으로 스톡이 줄면(귀국 > 신규) 5~7년 후 모수 감소. 그러나 그 전에 누적 재고 + E-8 회전이 충분히 큼 → 1~3년 타이밍 창엔 영향 미미.

### 3.2 가사관리사 본사업 미추진 확정 (돌봄 확장 역풍, 단 BackWon엔 미세 순풍)

`[1차]` 2025.12.22 외국인력정책위 — **"외국인 가사관리사 시범사업은 본사업을 추진하지 않되, 현 근무자는 다른 E-9와 동일하게 취업활동기간 연장 등 적용."** (출처: [다음/연합 종합](https://v.daum.net/v/20251222192443212))

**번역**: PROJECT.md "가사관리사 보류"는 **"보류"가 아니라 "본사업 미추진(사실상 종료)" 확정** — 더 강한 표현으로 갱신 필요. 돌봄 확장은 요양(E-7-2)으로 재포커스(내부 분석 정합). 한편 시범사업 종료자도 정산·환급 대상이 되므로 BackWon 출국정산엔 미세한 일감.

### 3.3 [신규 발견·내부 분석 누락] 한패스 외국인 대안신용·대출비교 진입 — R3 길목 역풍

`[2차]` **한패스(Hanpass), 2026.2.25 주한 외국인 전용 대출비교 서비스 출시.** 비자유형·소득·금융이력 입력 → 제휴 금융사 대출상품 비교. **매달 40만건+ 송금 트랜잭션 + 월렛 결제 + 체류 이력을 AI 대안신용평가 모델에 접목** 계획. (출처: [뉴시스 NISX20260225_0003525831](https://www.newsis.com/view/NISX20260225_0003525831))

**번역 (Risk)**:
- BackWon R3의 핵심 가설("고용+금융 데이터 = 외국인 신용스코어")의 **금융·송금 쪽 데이터 우위를 한패스가 이미 보유**(40만건/월 송금). PROJECT.md 경쟁 분석은 클링커즈(glow)·vivisa만 워치했으나 **한패스가 송금→대안신용 길목에서 가장 앞섬**.
- 단, **한패스는 B2B 고용·재직 데이터가 없다.** BackWon의 right-to-win은 여전히 **VisaDesk 고용·재직·급여 신호**(한패스가 못 가진 축)와의 결합. → R3는 "한패스와 같은 송금 신용"이 아니라 **"고용·재직 신호 제공자(B2B 데이터)"로 차별화**해야 생존. 직접 송금/신용스코어 정면승부는 패배 가능성.

`[1차]` 금융·신용 영역은 직접 진입 금지선이 명확:
