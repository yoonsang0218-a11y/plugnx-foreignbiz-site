# WS17 — BackWon Value-First 사업 방향 구체화

> 작성 기준일: 2026-06-30 KST
> 요청: "돈을 버는 것보다 외국인 재직자, 외국인 구직자들에게 어떤 가치를 줄지가 더 높은 순위가 되어야겠네... 사업 방향을 구체화"
> 사용 스킬: `newbiz-strategy` · `moneeback-refund`
> 핵심 관점: BackWon은 데이터를 팔기 위해 유저를 모으는 서비스가 아니라, 외국인의 일·돈·체류 문제를 해결해 **신뢰 가능한 노동자/구직자 자산**을 만들고, 그 결과로 금융권 신호와 사업자 가치가 생기는 서비스다.
> 면책: 비자·노무·세무·법률·금융 판단은 법적 효력 없는 참고 정보다. 제품화 전 전문가 검토와 최신 1차 출처 확인이 필요하다.

---

## 1. Answer First

BackWon의 사업 방향은 아래 한 문장으로 바꿔야 한다.

> **외국인 재직자·구직자가 한국에서 더 좋은 일자리, 더 안전한 체류, 더 정확한 정산, 더 넓은 금융접근을 얻도록 돕고, 그 과정에서 생기는 신뢰 신호를 본인 동의 기반으로 사업자와 금융권에 연결한다.**

우선순위는 명확하다.

1. **외국인 개인 가치**: 일자리·소득·권리·금융접근·체류 안정성
2. **사업자 가치**: 채용 실패 감소·온보딩 효율·근속·노무/체류 리스크 감소
3. **금융권 가치**: 기존 금융 데이터로 보이지 않는 재직·소득·체류·보험 신호
4. **BackWon 수익**: 금융권/CB/사업자/전문가 SaaS에서 발생

즉, 수익모델은 뒤에 있고, 제품의 앞면은 **외국인을 더 강한 근로자·구직자로 만들어주는 도구**여야 한다.

## 2. 새 포지셔닝

### 기존 표현

| 표현 | 문제 |
|---|---|
| 환급앱 | 이벤트성, 출국 시점 의존, 정부 무료서비스와 비교됨 |
| 금융 데이터 레이어 | 유저 입장에서 차갑고 수탈적으로 보일 수 있음 |
| 금융권에 외국인 정보를 판다 | 신뢰·동의·브랜드 리스크가 큼 |

### 바꿀 표현

| 새 표현 | 의미 |
|---|---|
| BackWon Work Passport | 외국인의 일·돈·체류·서류 신뢰 자산 |
| 외국인 커리어·정산 도우미 | 구직부터 재직, 전환, 출국정산까지 지원 |
| 사업자용 외국인 워커케어 인프라 | 직원이 오래 일하고 문제 없이 정착하게 하는 복지/운영 도구 |
| 동의 기반 신용 보강 리포트 | 금융권에는 점수 없는 원천 신호만 제공 |

**추천 슬로건**

> 외국인이 한국에서 일한 기록이, 더 나은 일자리와 금융 접근으로 이어지게.

## 3. 3자 가치 구조

### 3.1 외국인 재직자 가치

| 가치 | 구체 기능 | 데이터 부산물 |
|---|---|---|
| 내가 받을 돈을 놓치지 않음 | 국민연금, 퇴직금, 출국만기보험, 귀국비용보험 체크 | refund_intent, contribution_signal |
| 급여와 공제를 이해함 | 급여명세 OCR, 최저임금/공제/체불 신호 | salary_history, wage_risk_flag |
| 체류와 서류를 놓치지 않음 | 체류만기, 주소변경, 여권변경, 사업장변경 체크 | stay_stability, document_freshness |
| 은행에서 나를 설명할 수 있음 | 재직·급여·체류·보험 증빙 패키지 | readiness_report |
| 회사와 말하기 어려운 문제를 정리함 | 상담 전 intake, 레드플래그, 공식기관/전문가 라우팅 | issue_type, resolution_status |

### 3.2 외국인 구직자 가치

| 가치 | 구체 기능 | 데이터 부산물 |
|---|---|---|
| 내가 지원 가능한 일을 이해함 | 비자별 취업가능 범위, 필요 서류 체크 | work_eligibility_signal |
| 사기/위험 채용을 피함 | 사업장 정보, 계약서 위험 키워드, 임금 조건 체크 | job_risk_flag |
| 더 좋은 일자리를 준비함 | 경력·교육·자격·한국어 포트폴리오 | career_stability_signal |
| 면접/입사 서류를 쉽게 냄 | 다국어 프로필, 경력 PDF, 증빙 월렛 | candidate_profile_completeness |
| 입사 후 바로 금융 준비를 시작함 | 첫 급여부터 급여명세/입금 기록 축적 | income_start_signal |

### 3.3 사업자 가치

| 사업자 문제 | BackWon 제공 가치 | 결과 |
|---|---|---|
| 외국인 채용 후 서류/설명 반복 | 근로자 self-service 서류 월렛과 다국어 안내 | HR 문의 감소 |
| 체류만기·주소·여권 변경 누락 | 근로자 쪽 알림 + 사업자 확인 플래그 | 준법 리스크 감소 |
| 급여/보험/퇴직금 오해 | 근로자에게 설명 가능한 정산 카드 | 분쟁 예방 |
| 근속률 낮음 | 금융접근, 권리 확인, 생활 안정 지원 | 체감 복지 상승 |
| 좋은 구직자 선별 어려움 | Work Passport 기반 준비도/서류 완성도 | 온보딩 속도 개선 |

사업자는 "데이터 판매자"가 아니라 **외국인 직원에게 좋은 도구를 제공하는 후원자/운영자**가 되어야 한다.

### 3.4 금융권 가치

| 금융권 문제 | BackWon 신호 |
|---|---|
| 외국인은 thin-file이라 심사하기 어려움 | 재직·급여·체류·보험·주소 신호 |
| 계좌 안에 급여가 없어 소득 확인이 어려움 | 급여명세+입금내역+계약서 교차검증 |
| 체류만기 리스크가 보이지 않음 | visa_type, months_to_expiry, document_freshness |
| 사후 부실 리스크 관리가 어려움 | 월간 report_freshness, employment_status_update |

금융권에 파는 것은 "개인정보 원본"이 아니다. **사용자 동의로 생성된 점수 없는 신호 리포트**다.

## 4. 제품 방향: 4개 Passport

### 4.1 Job Passport

대상: 외국인 구직자

핵심 기능:
- 비자별 지원 가능 직무/사업장 체크
- 다국어 이력/경력/교육 프로필
- 자격·교육·한국어 기록
- 계약서/채용공고 위험 키워드 체크
- 입사 전 필요서류 체크리스트

사업자 가치:
- 지원자 서류 완성도 확인
- 입사 가능성/온보딩 리스크 감소
- 좋은 구직자 풀 확보

금융권 신호:
- 아직 금융 판매 대상은 아님
- 미래 재직/소득 신호의 seed 데이터

### 4.2 Work Passport

대상: 외국인 재직자

핵심 기능:
- 근로계약서/재직/급여명세 월렛
- 급여·공제·체불 신호
- 체류만기/주소/여권/사업장 변경 알림
- 회사와 공유 가능한 증빙 패키지

사업자 가치:
- HR 문의 감소
- 준법 리스크 조기 발견
- 직원 신뢰와 근속 개선

금융권 신호:
- 재직 안정성
- 급여 연속성
- 체류 안정성

### 4.3 BackWon Passport

대상: 퇴직/출국/전환 시점 외국인

핵심 기능:
- 국민연금 반환일시금 체크
- 퇴직금/출국만기보험/귀국비용보험 체크
- 출국 D-90/D-30 체크리스트
- 공식기관/보험사/노무사 라우팅

사업자 가치:
- 퇴직·출국 정산 분쟁 예방
- 마지막 경험 개선
- 재입국/추천 가능성 개선

금융권 신호:
- 기여/보험 증빙
- 정산 이벤트
- 연락 지속성

### 4.4 Finance Passport

대상: 금융상품을 원하거나 신용 보강이 필요한 외국인

핵심 기능:
- 점수 없는 금융 준비도 리포트
- 부족 서류 안내
- 금융권 제공 동의센터
- 조회 로그와 철회권

사업자 가치:
- 직원 복지로 금융 접근 제공
- 급여 인상 외 복지 레버

금융권 신호:
- identity, stay, employment, income, contribution, residence, red_flags

## 5. 사업 방향의 핵심 플라이휠

```text
외국인에게 실질 가치 제공
→ 본인이 자발적으로 서류·급여·체류 정보를 업데이트
→ 신뢰 가능한 Work Passport 완성
→ 사업자는 온보딩·근속·준법에서 가치 체감
→ 금융권은 동의 기반 신호를 조회
→ 금융 접근성이 좋아짐
→ 외국인은 더 자주 돌아와 정보를 갱신
```

중요한 점은 **데이터 품질은 설문으로 얻는 게 아니라 유저가 매달 쓸 이유가 있을 때 생긴다**는 것이다.

## 6. 사업자에게 주는 가치: "복지 + 운영 + 준법"

사업자는 BackWon에 직접 데이터를 팔거나 현금을 받는 주체가 아니다. 대신 BackWon은 사업자에게 아래 3가지 가치를 줘야 한다.

| 가치축 | 기능 | 사업자 메시지 |
|---|---|---|
| 복지 | 직원 금융 준비도, 환급/정산 안내, 다국어 도움 | "직원에게 월급 외 체감 복지를 제공합니다." |
| 운영 | 서류 월렛, 알림, self-service FAQ | "외국인 직원 문의와 반복 설명을 줄입니다." |
| 준법 | 체류만기, 급여/공제 위험, 보험 체크 | "문제가 커지기 전에 조기 발견합니다." |

사업자용 제품은 VisaDesk와 연결하되, BackWon 단독으로도 **Worker Care Pack** 형태로 제안할 수 있다.

### Worker Care Pack

| 구성 | 설명 |
|---|---|
| 직원 초대 링크 | 회사가 외국인 직원에게 BackWon Passport 초대 |
| 서류 요청/완료 현황 | 직원별 필수서류 완료율만 확인 |
| 체류/보험/급여 알림 | 세부 민감정보 없이 위험 플래그만 표시 |
| 정산/퇴직 체크 | 출국·퇴직 시 체크리스트 제공 |
| 금융복지 연결 | 직원 동의 기반 금융 준비도 안내 |

**주의:** 사업자에게 근로자의 민감한 금융정보를 직접 노출하지 않는다. 사업자는 완료/위험/필요조치 수준의 운영 플래그만 본다.

## 7. 유저 가치 우선 KPI

기존 KPI는 금융권 조회 전환에 치우치면 안 된다. 아래 순서로 봐야 한다.

### 7.1 1순위: 외국인 가치 KPI

| KPI | 의미 |
|---|---|
| first_value_time | 가입 후 첫 유용한 결과까지 걸린 시간 |
| document_pack_completed | 구직/재직/금융용 기본 서류 패키지 완성률 |
| monthly_update_rate | 월 1회 이상 급여/체류/서류 업데이트율 |
| issue_resolved_rate | 환급·체불·체류·서류 문제 해결률 |
| financial_readiness_improved | 부족서류 감소 또는 리포트 완성도 개선 |

### 7.2 2순위: 사업자 가치 KPI

| KPI | 의미 |
|---|---|
| employee_activation_rate | 초대한 직원 중 활성화 비율 |
| hr_ticket_reduction | 반복 서류/정산 문의 감소 |
| compliance_flag_closed | 체류/서류/보험 플래그 처리율 |
| retention_proxy | 재직 유지·이탈 위험 개선 추정 |

### 7.3 3순위: 금융 BM KPI

| KPI | 의미 |
|---|---|
| finance_opt_in_rate | 금융권 제공 동의율 |
| report_query_rate | 동의 리포트 조회율 |
| partner_paid_poc | 유료 PoC 전환 |
| report_field_utilization | 금융사가 실제로 쓰는 필드 |

## 8. 12주 실행 방향

### 1-4주: 외국인 가치 검증

목표: 외국인이 BackWon을 "쓸 이유"가 있는지 검증

- Job/Work Passport 프로필
- 급여명세/계약서/체류 서류 월렛
- 환급/정산 체크
- 부족서류와 오늘 할 일
- 6개 언어 핵심 UX

검증 기준:
- 가입 후 10분 내 첫 가치 도달
- 기본 서류 2종 이상 업로드율
- 월간 재방문/업데이트 의향

### 5-8주: 사업자 가치 검증

목표: 사업자가 직원에게 배포할 이유가 있는지 검증

- 직원 초대 링크
- 직원별 완료율/위험 플래그
- 체류/서류/정산 알림
- Worker Care Pack 제안서

검증 기준:
- 사업자 5-10곳 파일럿
- 직원 초대 전환율
- HR 문의 감소 체감 인터뷰

### 9-12주: 금융권 가치 검증

목표: 금융권이 어떤 신호에 돈을 낼지 검증

- scoreless report sample
- 파트너 필드별 RFI
- 동의/조회 로그 PoC
- 리포트 단가/과금 구조 인터뷰

검증 기준:
- 금융권/CB 2-3곳 RFI
- 실제 사용 필드 5개 이상 확인
- 유료 PoC 조건 도출

## 10. 최종 방향

BackWon은 "외국인 금융 데이터 판매 서비스"가 아니다.

**BackWon은 외국인 재직자와 구직자의 일한 기록, 받을 권리, 체류 안정성, 금융 준비도를 본인 소유의 신뢰 자산으로 바꿔주는 서비스다.**

사업자는 그 자산을 통해 더 안정적으로 채용·운영하고, 금융권은 사용자가 허용한 범위 안에서 기존 금융 데이터로 보이지 않던 신호를 조회한다.

이 순서가 지켜져야 한다.

```text
외국인 가치
→ 사업자 가치
→ 신뢰 데이터
→ 금융권 수익
```
