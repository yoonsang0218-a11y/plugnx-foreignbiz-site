### 1.2 질문① — 점수 자동판정·로드맵의 위험은 어디서 발생하나

**자동판정·부족점수 로드맵 자체는 행정사법 업무가 아니다.** 공표된 고시 기준을 소프트웨어로 대조해 "현재 N점 [추정], 한국어 1단계 상승 시 +X점" 같은 **일반 기준의 기계적 안내**를 제공하는 것은 서류 작성도 제출 대행도 아니다. 위험은 판정이 아니라 **그 다음 단계의 산출물 형태**에서 발생한다.

경계가 갈리는 지점 — "작성" 실질의 4요소 [추정/판례 경향 종합]:
1. **최종 문서를 누가 생성하는가** — 플랫폼이 완성된 신청서 서식(하이코리아 통합신청서 등)을 뽑아주면 '작성' 실질에 근접.
2. **기재 내용의 판단을 누가 하는가** — 어떤 값·표현을 쓸지 플랫폼이 결정해 주면 위험 가중.
3. **대가가 무엇에 결부되는가** — "서류 완성"에 과금이 붙으면 '업으로 작성' 외관.
4. **제출 행위 관여** — 플랫폼 명의·계정의 제출은 명백한 대행(행정사법 + 출관법 §79의2 이중 위반).

따라서 위험 사다리는: **체크리스트·준비물 목록·기재 항목 설명(🟢) → 사용자 데이터를 정리한 '데이터 시트'(서식 아님)(🟢~🟡) → 신청서 서식 자동완성본 PDF(🟡~🔴) → 플랫폼 명의 작성·제출(🔴)**.

> 참고: 세무 분야의 삼쩜삼이 "본인 신고 도구" 논리로 동일 구조를 방어해 왔으나, 세무사법은 '26.6 오인광고 금지로 응수했다[내부/WS4]. 행정사법에는 아직 §27②(노무사)·§20③(세무사)형 **오인 표시·광고 금지 일반조항이 확인되지 않으나**(§3② 명칭 사용 금지만 확인 [확인필요]) 동일 입법 패턴이 확산 중이므로 표현 설계는 처음부터 보수적으로 간다.

### 1.3 질문② — 유료 상품화 시 안전한 상품 정의·문구

**유료화 가능한 실체**: ① 판정+로드맵+고시 개정 알림의 **정보 구독**(근로자·기업 애드온) ② 본인 업로드 서류함·만료 알림 등 **정리 도구** ③ 다국어 **기재 안내 콘텐츠**. 유료화 불가(본인용): 신청서 자동완성·검토("이대로 내면 됩니다")·제출.

| 🟢 해도 되는 것 | 🔴 하면 안 되는 것 |
|---|---|
| 점수 자동판정 + "참고용, 최종 판단은 출입국 심사" 고지 | "전환 보장" "승인 가능" 단정 (심사 재량 무시) |
| 부족점수 로드맵(일반 기준 안내) | 개별 사안 "이렇게 쓰면 통과" 맞춤 컨설팅 문구 |
| 준비물 체크리스트·발급처 안내·기재 항목 설명 | 신청서 서식 자동완성본을 본인에게 제공 |
| 본인 업로드 서류함 + 누락·만료 알림 | 플랫폼이 서류를 작성·보완·제출 |
| 대행 원할 때 등록 대행기관 라우팅(E6) | 미등록 행정사·무자격자 라우팅, 플랫폼 명의 전자민원 |
| 기업용 뷰: "전환 요건 충족 가능 인력 N명 [추정]" | 기업에 "우리가 전환시켜 드립니다" |

**금지 표현 → 권장 표현**:

| 금지(🔴) | 권장(🟢) |
|---|---|
| "E-7-4 신청 서류를 만들어 드립니다" | "본인이 직접 제출할 때 필요한 준비물을 한 화면에 정리해 드립니다" |
| "서류 준비 패키지" (작성 대행 오인 소지) | "전환 준비 체크리스트" / "본인 제출용 준비 가이드" |
| "점수 판정 결과 전환 가능합니다" | "공표된 점수 기준으로 계산한 참고 결과입니다. 실제 허가는 출입국·외국인청의 심사로 결정됩니다" |
| "신청 대행 포함" | "제출 대행이 필요하면 **출입국민원 등록 대행기관**(행정사·변호사)을 연결해 드립니다" |

### 1.4 질문③ — 출입국관리법 등록 대행기관 제도와의 관계

출입국 민원 대행은 일반 행정사법보다 **한 겹 더 좁다**: 출관법 §79의2에 따라 **출입국관청에 등록한 변호사·행정사(대행기관)만** 체류자격 변경 등 신청을 대행할 수 있고, 기술행정사·외국어번역행정사는 등록 대상에서 제외된다 [1차/관리지침]. 함의 3가지:

1. **E6 파트너 온보딩 요건에 "대행기관 등록번호" 확인을 필수화**한다. E-7-4 건은 '아무 행정사'가 아니라 등록 대행기관만 받을 수 있다. (WS21이 경쟁 지도에 올린 refundcheck.kr가 "법무부 등록 대리인" 번호를 전면 노출하는 것과 동일한 신뢰 신호 — 파트너 프로필에 등록번호 표기.)
2. **플랫폼 자신은 대행기관이 될 수 없다**(자격사가 아님). 등록 없이 대행 시 행정사법 §36 + 출관법 위반이 중첩된다(출관법 자체 벌칙·과태료 조항은 [확인필요]).
3. 파트너 관리 리스크: 관리지침상 대행기관 등록취소 사유에 "외국인에게 과장·거짓 정보 제공" 포함 [1차] → **우리 마케팅 소재가 파트너의 지침 위반을 유발하지 않도록**(예: "100% 전환") 파트너 제공 카피도 동일 기준으로 관리.

### 1.5 과금 설계 권고 (E3)

- **근로자**: 판정·로드맵·체크리스트 = 무료~저가 구독(정보서비스 명목). 서류 '완성'에 과금 금지.
- **기업**: "전환 가능 인력 대시보드" 애드온(Growth→Compliance 업셀 — WS21 설계 유지). 과금 명목은 **인력 유지 계획 정보** 제공이지 신청 성사가 아니다.
- **신청서 자동완성 기능을 살리는 합법 경로**: 본인용이 아니라 **E6 파트너(등록 대행기관) 전용 백오피스 도구**로 제공 — 작성 주체가 자격사가 되므로 경계 문제가 소멸하고, E6의 "서류 완비" 가치가 강해진다. [추정/권고 — 변호사 검토 후 확정]

### 2.2 질문① — 자가진단 결과 표시의 경계

**위험의 구조**: "체불 가능성 높음" 같은 표시는 ⓐ개별 사안에 대한 **법적 평가의 외관**(변§109 '감정'·'법률상담' 논란 — 단 §109는 유상성 요건이 있어 **무료 자동화 서비스면 성립 여지가 낮다** [추정/변호사 검토]) ⓑ 유·무료 불문 **공노법 §27② 오인 광고**(노무사 직무인 '노동관계법령 상담·권리구제'를 수행하는 것처럼 보이는 표시) 두 경로로 문제될 수 있다. ⓑ가 더 현실적인 위협이다 — 세무사회가 삼쩜삼을 친 것과 동일한 방식으로 노무사회가 칠 수 있는 조항이 **이미 2020년부터 존재**한다.

**안전 원칙 — "법적 결론"이 아니라 "산술 대조 사실"을 말한다**:

| 🟢 해도 되는 것 | 🔴 하면 안 되는 것 |
|---|---|
| 법정 기준(최저임금·주휴 등 공표 산식) 대비 입력값의 **산술 차이 표시** + 산식 공개 | "체불입니다" "체불 가능성 높음" 등 **법적 성격 규정·확률 단정** |
| "차이가 있습니다 → 고용노동부 1350·법률구조공단(무료)에서 확인하세요" 정부채널 우선 안내 | 승소·수령 가능성 평가("받을 수 있습니다") |
| 노무사·변호사 **디렉토리 연결 선택지**(사용자가 선택) | 특정 전문가 자동 배정 + 그 대가 수취 |
| "본 결과는 법률 판단이 아닌 참고 정보" 고정 고지 | 노무사 직무 수행 오인 카피("노무 진단해 드립니다") |
| 다국어 권리 교육 콘텐츠(일반 정보 — 공노법 §27①이 3호 상담·지도를 제한하지 않는 공간) | 개별 사건에 대한 유상 맞춤 상담(변§109·공노법 경계) |

**금지 표현 → 권장 표현**:

| 금지(🔴) | 권장(🟢) |
|---|---|
| "체불 가능성 높음" | "입력하신 실수령액이 법정 기준으로 계산한 금액보다 **N원 적습니다** [추정]. 정확한 판단은 고용노동부(1350) 또는 전문가 확인이 필요합니다" |
| "임금체불 진단" (대외 명칭) | "급여 셀프 체크" / "내 급여 확인하기" |
| "산재 해당 여부를 판정해 드립니다" | "산재보험 신청 절차와 무료 지원 채널을 안내해 드립니다(근로복지공단·1350)" |
| "전문 노무 상담 제공" | "필요 시 공인노무사·변호사를 찾아볼 수 있게 연결해 드립니다(별도 위임계약은 본인↔전문가)" |

### 2.3 질문② — 라우팅 수익화: 되는 것과 안 되는 것

선례 양극단이 답을 준다:
- **되는 쪽(로톡 모델)**: 전문가로부터 **정액 광고료·구독료**(노출 대가, 사건 수·수임 여부와 무관) — 법무부가 "§34 위반 아님"을 명시 [1차/행정].
- **안 되는 쪽(강남언니 모델)**: 소개 **성사 기반 건당·거래액 비례** 수수료(진료비의 9.7%) — 알선 대가로 유죄(의사 벌금 300만원, 운영사 대표 2심 징역 8월 집유 2년). 의료법 사건이지만 "소개·알선·유인의 대가" 구조 판단은 자격사법 전반에 이식 가능한 신호다 [1차/법원 — [법률신문](https://www.lawtimes.co.kr/news/articleView.html?idxno=189061) · [리걸타임즈](https://www.legaltimes.co.kr/news/articleView.html?idxno=67750)].

적용:
1. **변호사 연결**: §34①·② — 수임 연동 대가는 어느 방향(근로자에게서든 변호사에게서든)이든 금지. 정액 광고·디렉토리(사용자 선택)만. 근로자에게 "소개비" 수취도 §34① 금지.
2. **노무사 연결**: 공인노무사법에는 변§34와 동형의 제3자 알선대가 금지 조문이 **본 점검에서 확인되지 않았다** [확인필요 — 노무사법 전수 및 윤리규정 검토]. 그러나 ⓐ노동청 진정·산재 사건은 '법률사건'으로서 변§109의 유상 **알선** 포섭 위험이 있고 ⓑ§27② 오인 광고 리스크가 있으므로, **변호사 연결과 동일한 정액 원칙을 적용**하는 것이 안전하다.
3. **정부 무료 채널 우선 배치**(WS21 설계)는 유지 — "알선으로 돈 버는 구조가 아님"을 보여주는 가장 강한 정황 방어막이자 신뢰 앵커.

### 2.4 질문③ — 진행상태 트래킹이 "사건 관여"로 보일 위험

| 🟢 안전(물류·표시) | 🔴 위험(사건 개입) |
|---|---|
| 전문가/사용자가 입력한 **단계 상태의 표시**(접수→진행→종결) | 플랫폼이 진정서·청구서 내용을 작성·수정·보완 지시 |
| 일정·기한 알림, 서류 전달 이력 로그 | 상대방(사용자의 고용 기업)과의 교섭 메시지를 플랫폼이 작성·중개 |
| 다국어 **통·번역**(전문가 발언의 번역 전달) | 전문가 조언을 플랫폼이 **재해석·요약해 자체 조언처럼** 전달 |
| 만족도 평가·완료 확인 | 진정 취하·합의 권유 등 처분 관여 |

**이해충돌 특칙**(WS21 §E5 "익명 리스크 플래그만" 설계 지지 + 강화): 신고·진단 사실과 내용은 **해당 기업(B2B 고객)에 절대 비노출**. 기업측 뷰에는 사업장 단위 익명 통계 플래그만. 내부적으로 E5 데이터와 VisaDesk 기업 대시보드 사이에 **접근 차단벽**(권한 분리·감사로그 — ForeignID 동의센터 원칙 적용)을 문서화해 둔다. 이것이 무너지면 법 이전에 "고용주 앱이 근로자를 감시한다"는 신뢰 붕괴로 동의율 해자(passport-moat 해자 4)가 죽는다.

### 2.5 과금 설계 권고 (E5)

**E5 자체는 무료를 유지한다**(WS21의 "신뢰 앵커·동의율 장치" 포지션과 일치 — 유상성 제거는 변§109 방어에도 유리). 수익화는 E6의 정액 구조로만 흘린다. E5 화면에는 광고·유료 연결 배너를 두지 않는다(오인 광고 표면적 최소화).

계약·회계 처리: 파트너 계약서와 세금계산서의 품목을 "**서류 정리·번역·전달 용역**"으로 명기하고, "소개·알선·중개" 문언을 계약 전체에서 배제. 광고성 노출(프로필 상단 등)을 판다면 **별도의 정액 광고 상품**으로 분리 계약(용역 fee와 혼합 금지).

### 3.4 질문③ — 개인정보 제3자 제공 동의 설계 요건

**구조 판정이 먼저다**: 파트너 전문가는 수임 사무를 **자기 책임·자기 목적**으로 처리하므로 이 전달은 '처리위탁'(§26)이 아니라 **'제3자 제공'(§17)** 구성이 원칙이다 [추정/법무 확정 필요 — 위탁으로 잘못 구성하면 동의 없는 제공이 되어 전체가 무너진다].

설계 요건 체크리스트:
- [ ] **건별·전문가별 동의**: "제휴 전문가 일반"에 대한 포괄 동의 금지 — 받는 자(사무소명)를 특정해 그때그때 동의. 5요소(§17②) 전부 고지.
- [ ] **고유식별정보 별도 동의**(§24①): 외국인등록번호·여권번호 포함 시 일반 동의와 분리된 체크. 애초에 **패키지에서 번호를 뺄 수 있으면 뺀다**(최소수집 — 전문가가 위임계약 후 본인에게서 직접 수집하는 흐름이 더 안전).
- [ ] **민감정보 별도 동의**(§23): 산재 건의 부상·진단 정보.
- [ ] **다국어 동의 화면**(§22 이해가능성): 6개 언어. 법률 문구 원문+모국어 요약 병기 [확인필요/개인정보위 외국인 동의 가이드].
- [ ] **최소 항목 전달**: 사건 관련 기간·항목만(재직 전체 이력·급여 전 기간 일괄 전달 금지). 기업 원장 유래 데이터는 **근로자 본인 동의가 유일한 근거**(B2B 계약으로 갈음 불가 — SSOT·WS4 §3 동일).
- [ ] **철회·파기 흐름**: 동의 철회 시 전달 중단 + 파트너측 파기 요청 절차를 파트너 계약에 포함. ForeignID 동의센터·감사로그로 제공 이력 증적(passport-moat §7-4 데이터 계약 원칙과 동일 레일).
- [ ] 파트너측 안전조치 의무(암호화 수신·목적 외 이용 금지·재제공 금지)를 계약으로 부과.

## 5. 확인 필요 잔여 (전문가 검토 필수 항목)

1. `[확인필요/행정사]` 행정사법 §36①1 벌칙이 §2①의 **각 호 전부**에 미치는지, 1~5호 한정인지(6호 '상담·자문' 포함 여부) — 법제처 원문 대조. E3 정보 구독 상품의 안전 폭을 결정.
2. `[확인필요/행정사]` 출입국관리법 §79의2 위반(미등록 대행) 시 출관법 **자체 벌칙·과태료** 유무(§93~§100) 및 행정사법과의 경합 관계.
3. `[확인필요/변호사]` 변§109 '법률사건 **알선**'이 **적법 자격자(노무사·등록 행정사)에게 유상 연결**하는 경우까지 포섭되는지 — 판례·법무부 유권해석. E6 건당 정액(모델②)의 최종 승인 조건.
4. `[확인필요/노무사]` 공인노무사법·윤리규정상 제3자 사건 소개 대가 금지 조항 유무 전수 확인(§28 벌칙 값 원문 재대조 포함).
5. `[확인필요/법무부 고시]` K-point E74 점수제 최신 고시 — 소득 기준(2,600만원 [2차])·배점표·지역특화(107개 [SSOT]) 수치의 개정 확인 + E3 판정 로직의 **고시 버저닝** 체계(개정 시 자동 재계산·이용자 고지).
6. `[확인필요/개인정보 법무]` E6 전달 구조의 제3자 제공 vs 처리위탁 최종 구성 + 외국인 대상 **다국어 동의의 적법 요건**(개인정보위 가이드·해석례) + 산재 건강정보 §23 처리 흐름.
7. `[확인필요/변호사]` E5 무료 제공 시에도 광고·데이터 수익 등 **간접 대가**로 변§109 유상성이 구성될 여지 — 서비스 약관·BM 문서 검토.
8. `[내부/WS4 크로스레퍼런스]` 세무사법 '26.6 시행 오인광고 금지(E1 세금 칸)·전송요구권 수신기관 범위 — WS4 §5.1에서 이미 관리 중, 본 건 범위 밖.
