## 0. 결론 (Answer First)

1. **두 진영 모두 "정교한 대안신용평가"로 대출하는 게 아니다.** 현행 외국인 심사의 실체는 ① 비자 유형 필터(E-9=고용허가제라는 정부 검증 고용의 프록시) ② CB 최저 컷(OK저축은행은 NICE 300점) ③ **종이 재직·소득 서류** ④ 잔여 불확실성은 **금리 10~20%로 전가** — 이 4단이다.
2. **한패스는 독립 사업자가 아니라 JB금융 연합군이다.** JB금융(지주·전북은행·JB인베)이 '23.12 지분 15%를 취득한 2대 주주 [1차/공식-JBFG]. 진짜 심사모형 보유자는 전북은행(2015~ 자체 상환이력 24만 명, 잔액 1조·'26.3)이고, 한패스는 트래픽·송금데이터 공급자다.
3. **glow는 유통(모집) 레이어만 완성했고 심사는 은행 몫이다.** 대출모집법인 2곳(광주은행계 희망플랜·OK저축계 윈인베스트먼트) 인수 + '26.3 금감원 등록 [1차/자사 공표] — 그러나 자체 신용평가 모형 없음, vivisa×클링커즈 대안신용평가(ACSS)는 MOU('25.12)뿐 제품·금융사 적용 0건.
4. **벤치마킹 함의: 금리 스프레드(가산 7~15%p)의 정체는 "재직·임금 불확실성 프리미엄"이고, 이를 깎을 수 있는 고용주 검증 재직·임금 데이터 스트림은 어느 심사에도 없다.** BackWon 금융여권은 유통 경쟁(모집·비교, 이미 한패스·glow 2강)이 아니라 **심사 4단계(서류 검증)를 API 신호로 대체하는 언더라이팅 보완재**로 들어가야 한다.

## 2. "금리를 낮추는" 레버 — 그들이 이미 증명한 것

현행 시장에서 금리가 실제로 낮아지는 경로는 세 가지뿐이며, 전부 **"검증된 신호가 늘면 스프레드가 준다"** 는 같은 원리다.

| 레버 | 증거 | 한계 |
|---|---|---|
| ① 자체 상환이력 축적 | 전북은행 자체 리스크 팩터 → 1금융임에도 외국인 취급 가능 | 10년 걸림. 후발 복제 불가 |
| ② 본국 CB 연계 | JB×CBC·CIC·CIBI, KCB×캄보디아 | 국가 커버리지 한정, 심사 실투입 여부 불명 |
| ③ 자행 급여이체 | 신한 SOL 글로벌론 "3개월 연속 급여 수령" 조건 | 자행 계좌에 묶임 — 타행·현금 급여 사각 |

→ **④ 고용주 검증 재직·임금 신호(실시간·월간 갱신)는 아무도 없다.** 이것이 BackWon 금융여권의 자리다. CB 점수(과거 금융이력)도, 송금 데이터(지출 행동)도 아닌 **"계속소득의 원천 검증"** 레이어.

## 3. BackWon 금융여권 벤치마킹 — 진입 설계

### 3.1 포지션: 유통이 아니라 언더라이팅 보완재

- **하지 말 것**: 대출비교·모집 경쟁(한패스 중개업+glow 모집법인 2강 완성, 라이선스·평판 리스크 — `06-finance-linkage-bm.md` N2 재확증).
- **할 것**: 심사 파이프라인의 "종이 서류" 단계를 대체하는 **동의 기반 검증 리포트/API**(점수 없음 — 신용정보법 회피, `backwon-financial-passport-moat.md` 스키마 v0.1 그대로).
- 금리 인하 논리를 은행 언어로: `employer_verified` + `salary_continuity_3m` + `visa_validity_months` 필드가 서류 위변조·재직 허위 리스크를 제거 → 은행 내부모형의 가산금리 구성요소 중 **정보 비대칭 프리미엄**을 직접 타격. PoC에서 "동일 차주에 필드 유/무로 승인율·금리 차이"를 측정하는 A/B 설계가 곧 세일즈 자료.

### 3.2 파트너 지도 (조사로 갱신)

| 진영 | 상태 | 우리 접근 |
|---|---|---|
| JB계열(전북·광주)+한패스 | 자본으로 수직 결합된 연합군 — 데이터 파트너로서 우리 유인 낮음 | 후순위. 단 전북은행도 고용주 검증 신호는 없으므로 배제는 아님 |
| **비-JB 진영: 웰컴·OK저축, 시중은행(신한 SOL 등), 인뱅** | 외국인 CSS 부재·서류 심사 의존 = **제휴 공백 시장** | RFI 1순위 (moat 문서 Phase 2의 "은행/CB 5곳" 대상 구체화) |
| 대안CB(크레파스솔루션 — 국내 1호 전문개인신용평가업) | 통신·행동 데이터 기반, 고용 신호 없음 | 점수화 파트너 후보(우리 신호 → 크레파스 점수화 → 금융사) |
| NICE평가정보(Welko·본국 CB 게이트웨이) | JB 본국 CB 연계의 실행자이기도 함 | 보완재 포지셔닝(국내 고용·임금 신호 공급) |

### 3.3 분기 워치 트리거 (기존 G4에 추가)

1. 한패스 L3(송금 데이터 대안CSS)의 "계획→실심사 투입" 전환 여부.
2. vivisa×클링커즈 ACSS 제품 출시·금융사 적용 첫 사례.
3. glow 모집법인 2곳의 금감원 등록부 교차확인(현재 자사 공표만).
4. 본국 CB 연계(CIBI 등)의 심사 실투입 확인.

### 3.4 SSOT(PROJECT.md) 갱신 제안 — 사용자 승인 후 반영

- "R3 길목에 한패스 선점" → **"한패스=JB금융 지분 15%·2대 주주('23.12)인 JB 연합군"** 추가. 제휴 공백은 비-JB 진영이라는 함의.
- "온투업 재직기반 외국인 여신" 주체를 **한패스파이낸스(타이탄인베스트 인수·재편, '26.4.20, 잔액 ~338억)** 로 구체화.
- 클링커즈 "광주은행 대출법인 인수설" → **"모집법인 2곳 인수+금감원 등록 완료(자사 공표, 언론 부분 교차확인)"** 로 상향.
