외국인 신사업을 움직이는 PlugNX 하위에이전트 길드

각 캐릭터는 하나의 전문 판단을 맡습니다. 경쟁앱 정찰, B2B 지불의사 검증, 규제 레드라인 점검과 GTM 전장 설계까지 필요한 순간에 골라 소환할 수 있습니다.

길드원 도감

총 24명의 하위에이전트

전략 파티 시장, 타당성, 사업기획, GTM, 구현을 이어주는 신사업 라이프사이클 파티.
도메인 파티 VisaDesk, BackWon, ForeignID와 비자·환급·본인인증 사실관계를 지키는 전문 파티.
GTM 전략본부 세그먼트, 고객 인사이트, 포지셔닝, 가격, 채널, 영업, PoC, 사업성을 병렬로 굴리는 전장 지휘부.
특수 검증대 경쟁앱 전수조사, B2B 지불의사, 규제 레드라인을 반복 검증하는 소규모 정예 파티.
검색 조건에 맞는 길드원이 없습니다.

소환 규칙

하위에이전트는 이름을 직접 불러도 되고, 담당 임무를 말해도 됩니다. 예를 들어 competitor-app-research-agent로 glow와 Vijob 비교해줘처럼 호출하면 됩니다.

깊은 작업은 파일을 나눠 맡기고, `PROJECT.md`의 브랜딩·수치·공통 원칙을 기준으로 교차검증합니다.

전투 진형

  • 시장 판단: `market-researcher` → `newbiz-strategist`
  • 유료화 검증: `b2b-wtp-agent` → `gtm-value-pricing-agent`
  • 위험 점검: `regulatory-risk-agent` → `foreign-domain-expert`
  • PoC 실행: `gtm-launch-pilot-agent` → `gtm-sales-motion-agent`
