외국인 근로자가 출국·퇴직 때 받을 수 있는데 못 받는 돈(연금·퇴직금·보험)을 모국어로 안내·연결하는 것을 입구로, 사용자 동의 기반으로 외국인 금융 데이터 레이어(고용·임금 신호)로 확장하는 B2C 서비스. 환급·급여진단은 수익원이 아니라 동의·데이터를 얻는 미끼이고, 수익은 금융사에 동의기반 신호를 공급하는 데서 난다. VisaDesk(B2B)가 근로자를 자동 유입(CAC 0)시키는 양면 플라이휠의 수요 측 엔진.

한 장 요약 · Executive Summary

BackWon은 "환급 사업"이 아니라 외국인 금융 데이터 레이어 — 환급·급여진단은 동의·데이터를 얻는 입구(미끼)이고, 수익은 금융사에 동의기반 고용·임금 신호를 공급하는 데서 난다(점수 자체 산출은 금지).

왜 지금 · 정부 기조가 「양적 확대 → 수급 안정·관리·신뢰」로 전환. E-9 도입이 13만→8만('26, −38.5%)으로 줄며 무게가 신규 유입에서 존량(재직·전환·출국·정착) 관리로 옮겨감 — 출국·퇴직 시 환급은 존량 관리의 정중앙.

무엇을 · ① 국민연금 반환일시금·퇴직금·출국만기/귀국비용보험·고용보험·세금/임금오류를 항목별로 추정 안내·연결(직접 대행 아님) ② 급여 적정성(AI) 진단 ③ 사용자가 선택한 금융사에 필요한 항목만 보내는 동의 기반 고용·임금 신호로 확장.

왜 PlugNX인가 · 경쟁 B2C 앱(vivisa·dagachi·vijob·glow·한패스) 중 환급 트랜잭션에 진출한 곳은 없고(glow는 콘텐츠 진입 시작), 우리만 VisaDesk 고용 데이터 + ForeignID 인증을 가져 환급 정확도와 CAC 0 유입을 동시에 확보. B2C-first가 아니라 B2B가 먹이는 B2C가 차별점.

정직한 현실 · "미수령 N조"식 단정은 금지(추정). 반환일시금은 비자×국적×가입×최소기간 다축으로 갈리고, 확정액은 공단·고용센터·보험사 조회로만 확인. 단위경제의 생사는 금융 attach율(가정 15% = BEP) 단 하나에 달렸다 — 환급만이면 12개월 1~3억. DB 판매와 무허가 신용평가(점수 N점)는 금지선으로 둔다.

근로자 통증은 "받을 돈"으로 모인다.

금융 제휴 1순위 · 케이뱅크 외국인대출

케이뱅크에는 “외국인 DB”가 아니라 “BackWon 대출 준비도 패키지”로 제안한다.

케이뱅크의 공개 신용대출 요건은 재직기간·연 환산소득·국민건강보험 가입 근로소득자 여부가 핵심이다. BackWon은 외부 인증 체계나 고용주 확인 없이도, 사용자가 직접 입력·업로드한 급여·근속·보험·환급 정보를 정리해 대출 전 단계의 증빙 완성도를 높일 수 있다.

케이뱅크가 궁금한 것BackWon 단독으로 줄 수 있는 신호주의할 표현
재직·근속 요건을 갖췄는가사용자 입력 입사월, 근속기간 구간, 근로계약서 업로드 여부, 사업장 수고용주 확인 재직증명이 아니라 사용자 제출자료 요약
소득이 꾸준한가급여명세서 OCR, 최근 3~6개월 급여 일관성, 공제·체불 이상 신호, 연 환산소득 추정확정 소득이 아니라 사용자 제출 자료 기반 추정
근로소득자성 증빙이 있는가건강보험·국민연금·고용보험 가입 여부 자가체크와 증빙 업로드 상태공단 API 확인값이 아니라 증빙 준비 상태
상환 여력을 설명할 자료가 있는가퇴직금 발생 가능성, 국민연금 반환일시금, 출국만기·귀국비용보험, 환급 예상 범위담보·보증·확정 수령액 아님

전략 위치 · 양면 플라이휠의 B2C 축

BackWon은 단독 앱이 아니라, B2B가 먹이는 수요 엔진.

경쟁사가 못 푼 "B2C 모객 비용" 문제를, VisaDesk(B2B)가 근로자를 자동 유입시켜 CAC 0으로 해결한다.

① B2B

기업이 근로자 등록

VisaDesk에 외국인 직원 등록·검증 → 재직·체류·급여 데이터 발생.

② 유입

근로자 BackWon 유입

"받을 돈" 동기로 자발적 가입(CAC 0). 노출/가입 목표 60%+, 단 환급 실과금전환은 3~9%.

③ B2C

환급·진단 만족

모국어 환급·급여 적정성 → 신뢰·재방문 → 사용자 동의 기반 검증 신호 축적.

④ 되먹임

근속·유지 ↑

근로자 만족 → 기업 근속률↑ → VisaDesk 유지·확장 → ①로 순환.

5겹 해자 · ① 양면 네트워크 ② 고용+임금+동의 이력 = 금융사에 공급하는 동의기반 신호(점수 자체 산출 아님) ③ 정책 정합성(K-Trust·존량관리) ④ 전환비용 ⑤ ForeignID 인증 인프라. BackWon 단독으로는 ②③⑤가 약하지만, 플라이휠 안에서는 전부 작동. ARR 21/60억은 VisaDesk(B2B)가 86%+ 캐리 전제이고, BackWon 기여는 금융 attach 의존(환급만이면 12M 1~3억).

조건부

전환은 되나 1차 수익이 약하면 — 환급은 유입·동의 획득용 무료 훅으로 두고, 수익은 B2B 패키지와 금융 제휴 LOI 중심으로 이동.

NO-GO

환급 수요·전환·금융 연계 모두 미확인이면 — BackWon 독립 추진 보류, VisaDesk B2B 단일에 집중.
