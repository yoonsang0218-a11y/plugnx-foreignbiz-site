왜 B2C-first인가

기업용 SaaS를 바로 팔면 "엑셀로도 되지 않나"라는 반응을 넘기 어렵다. 반대로 외국인 개인의 환급·금융 니즈는 설명이 짧고, 그 과정에서 회사 확인 요청이 자연스럽게 생긴다.

B2B-first 한계

구매 필요성을 증명하기 전까지 영업비가 커진다

  • 기업은 엑셀·카톡·행정사로도 가능하다고 본다.
  • 산단·제조기업 방문영업은 초기 CAC가 높다.
  • 비자 만료 알림과 체크리스트만으로는 해자가 약하다.
  • 직원 개인의 환급·금융 데이터를 확보하기 어렵다.
B2C-first 장점

개인 니즈가 회사 리드와 은행 데이터 PoC로 전환된다

  • "내가 받을 수 있는 돈"은 가입 명분이 명확하다.
  • 검색·커뮤니티·QR·지인 공유로 웹 유입이 가능하다.
  • 정확한 결과를 위해 회사 재직·급여 확인이 필요해진다.
  • 동의 기반 체류·재직·소득 신호가 은행 PoC 샘플이 된다.

제품 구조

초기 제품은 앱이 아니라 웹이다. 외국인은 모바일 웹으로 즉시 진단하고, 기업은 PC 웹 콘솔로 관리하며, 금융권에는 동의 기반 Trust Profile을 제공한다.

B2C

BackWon

외국인 근로자의 환급·급여·금융 가능성을 확인하는 모바일 웹 진단 서비스.

B2B

VisaDesk

회사가 외국인 직원의 체류·재직·서류·금융 확인 요청을 관리하는 PC 웹 SaaS.

Infra

ForeignID

본인확인·동의·체류·재직 신뢰도를 표준화하는 공통 인증 레이어.

Finance

Trust Profile

은행이 볼 수 있는 동의 기반 외국인 근로자 신뢰 신호.

1. 모바일 웹 진단설치 없이 환급·금융 가능성 확인
2. 회사 확인 요청재직·급여·체류 확인 링크
3. 무료 리포트회사 관리 공백 시각화
4. 유료 구독VisaDesk Starter/Growth 전환
5. 금융 PoCTrust Profile 샘플 검증
6. 인프라 확장ForeignID 기반 금융 연계

핵심 고객 여정

같은 데이터가 개인, 회사, 금융권에서 서로 다른 가치로 전환된다. 아래 탭에서 각 이해관계자의 여정을 확인할 수 있다.

검색·공유·QR로 진입"외국인 환급", "국민연금 반환", "외국인 대출" 문제에서 시작한다.익명 방문자와 유입 채널 데이터가 쌓인다.
1분 진단국적, 비자, 재직기간, 월급, 회사명, 출국 예정 여부를 입력한다.환급·금융 니즈와 회사명 신호를 확보한다.
ForeignID L1/L2필요한 경우 여권, 외국인등록증, 통신 인증으로 신뢰도를 높인다.금융권에 제공 가능한 인증 레벨이 생긴다.
회사 확인 요청정확한 결과를 위해 담당자에게 재직·급여 확인 링크를 보낸다.B2B 리드가 직원 요청 형태로 발생한다.
금융 혜택 사전확인케이뱅크 등 제휴 금융 혜택을 동의 기반으로 확인한다.은행 PoC용 Trust Profile 샘플이 만들어진다.
직원 요청 수신"귀사 외국인 직원이 재직/급여 확인을 요청했습니다" 링크를 받는다.방문영업이 아니라 직원발 Pull 리드로 시작한다.
회사 인증사업자 정보, 담당자 이메일, 전화로 회사 Claim Page를 만든다.회사 단위 데이터 원장이 열린다.
무료 리포트 확인체류만료, 누락서류, 환급/금융 문의 유형을 본다.관리 공백이 눈에 보이는 문제로 전환된다.
직원 명단 업로드엑셀 또는 간단 입력으로 외국인 직원 정보를 등록한다.VisaDesk 데이터 원장이 시작된다.
유료 전환알림, 문서함, 월간 점검, 전문가 검토가 필요해진다.Starter/Growth/Compliance 플랜으로 전환한다.
PoC 샘플 검토익명/가명 처리된 Trust Profile 구조를 받는다.심사·온보딩 활용 가능성을 판단한다.
변수 검토체류기간, 재직기간, 급여 안정성, 회사 확인 여부, ForeignID 레벨을 본다.은행이 유효 신호와 무효 신호를 구분한다.
공동 랜딩외국인 금융혜택 사전확인 링크를 테스트한다.적격 리드와 전환율을 측정한다.
제휴 모델 선택리드 제휴, KYC Pack, 재직확인 API, Trust Signal 중 하나를 고른다.PoC가 사업화 옵션으로 전환된다.

자동 세일링 인프라

목표는 방문영업을 없애는 것이 아니라, 개인의 문제 해결 행동이 회사와 금융권을 끌어오게 만드는 것이다.

Growth Loop 1

환급 진단에서 회사 확인 요청으로

환급·금융 가능성의 정확도를 높이려면 회사 재직·급여 확인이 필요하다는 흐름을 만든다.

Growth Loop 2

금융 사전확인에서 회사 신뢰 데이터로

외국인 개인의 금융 혜택 요청이 회사 확인을 만들고, 은행 제출용 Trust Profile로 전환된다.

Growth Loop 3

동료 추천으로 회사 단위 요청 묶기

같은 회사·같은 국적 직원들이 링크를 공유하면 회사 담당자에게 묶음 요청으로 전달된다.

Growth Loop 4

전문가·송금사·은행 역소개

파트너가 진단 링크를 공유하고, 유입된 개인 요청이 다시 상담·금융·B2B 리드로 환류된다.

데이터 설계

초기에는 개인정보를 최소화하고, 금융거래 단계로 갈수록 필요한 신뢰 레벨만 추가한다. 은행에는 원본 DB가 아니라 동의 기반 요약 신호를 제공한다.

PoC 로드맵

PoC의 목적은 대출 출시가 아니라, PlugNX가 외국인 개인을 모으고, 회사 확인을 만들고, 은행이 볼 수 있는 신뢰 신호로 정리할 수 있음을 증명하는 것이다.

0~2주

B2C 진단 MVP

모바일 웹 환급·금융·체류 1분 진단, 회사명 입력, 회사 확인 요청, 한국어·영어·베트남어 우선 지원.

성공 기준

진단 완료율 40% 이상, 회사명 입력률 40% 이상, 확인 요청률 15% 이상.

3~4주

회사 Claim Page

직원 요청함, 무료 관리공백 리포트, 직원 명단 업로드, 유료 전환 리드 스코어링.

성공 기준

회사 응답 10곳, 리포트 열람률 60% 이상, 5개 회사 데이터 제공.

5~8주

VisaDesk 유료 PoC

PROJECT.md 기준 PoC 목표는 8주 15사 · 3,300만원. B2C 가입과 회사 전환을 동시에 검증한다.

성공 기준

15사 참여, BackWon 300명 가입, 6사 유료 전환, Trust Profile 100건.

3~6개월

제휴·반복 사용 검증

케이뱅크 신호 유효성 검증, 송금사/커뮤니티 유입, 행정사·노무사 패널, 월간 리포트 자동화.

목표

반복 사용과 금융권 관심을 실제 전환 데이터로 확인.

6~24개월

B2B SaaS와 금융 인프라화

VisaDesk Growth 플랜 강화, ERP/급여대장 연동, Money Passport, Trust Signal API, ForeignID L3 확장.

목표

12개월 ARR 21억원, 24개월 ARR 60억원.

수익모델

B2B 구독으로 데이터 원천 비용을 회수하고, B2C 환급·금융 전환으로 사용자를 확보하며, 금융권 신뢰 신호로 LTV를 확장한다.

GTM 실행안

초기 채널은 검색형 계산기, 외국인 커뮤니티, 송금사·금융사 제휴, 회사 확인 요청이다. 산단 방문은 보완 채널로 둔다.

유입 채널 우선순위

  • 검색형 계산기/SEO: 환급·대출·비자 키워드 유입.
  • 외국인 커뮤니티: 베트남·필리핀·네팔·우즈벡 등 언어권 확산.
  • 송금사/금융사 제휴: 금융 혜택 사전확인 유입.
  • 회사 확인 요청: B2B 리드 자동 생성.

첫 30일 목표

  • 모바일 웹 방문자 1,000명, 진단 완료 300명.
  • 회사명 입력 150명, 회사 확인 요청 50건.
  • 회사 응답 10곳, 무료 리포트 5곳.
  • 케이뱅크 전달용 Trust Profile 100건.

해자와 금지 방향

앱 설치는 해자가 아니다. 해자는 회사 확인 데이터, 양면 네트워크, Trust Profile 표준, 전문가 검토 기록, 전환비용에서 생긴다.

Moat

반복적으로 검증되는 데이터 흐름

  • 직원 요청을 통한 재직·급여·체류 확인 누적.
  • 근로자 요청이 회사를 끌고, 회사 등록이 다시 근로자 가입을 만든다.
  • 은행이 원하는 데이터 스키마로 체류·재직·소득 신호를 정리한다.
  • 월간 리포트, 문서함, 금융 혜택 이력이 전환비용을 만든다.
No-go

들어가면 안 되는 방향

  • 단순 비자 알림 앱, 일반 외국인 생활 슈퍼앱.
  • 외국인 DB 판매, 대출 보장 문구, 직접 신용점수 단정.
  • 환급 보장, 스테이블코인 송금 선진입.
  • 규제 검토 전 금융 실행 기능을 전면에 내세우는 전략.

의사결정 기준

이 사업은 조건부 GO다. B2C 유입, 회사 확인 요청, 유료 전환, 금융권 관심이 함께 확인되어야 한다.

GO 조건

  • 4주 내 B2C 진단 완료 300명.
  • 회사 확인 요청 50건, 회사 응답 10곳.
  • 유료 PoC 의향 2곳 이상, 8주 내 유료 전환 6사 이상.
  • 케이뱅크 포함 금융사 2곳 이상이 데이터 항목 검토.
  • Trust Profile 100건 이상 생성 가능.

PIVOT 조건

  • 회사 요청률이 낮으면 결과 화면의 회사 확인 필요성을 강화한다.
  • 유료 전환이 낮으면 SaaS 대신 월간 점검 리포트로 시작한다.
  • 금융사가 신호를 안 보면 KYC Pack·재직확인 API로 축소한다.
  • 환급 니즈가 약하면 대출·송금·계좌 사전확인으로 웨지를 바꾼다.
