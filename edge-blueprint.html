가져가야 할 서비스

엣지 서비스 6종.

각 서비스는 특정 경쟁군을 무력화하도록 설계됐고, 3개 층(입구→락인→수익화)으로 쌓입니다.

E1입구

Refund Radar — 떠나기 전에 이미 계산된 내 돈

연금+퇴직금+보험+세금 4분절 통합 조회 + 재직 중 실시간 환급 적립 대시보드(금액은 [추정] 상시 표기) + 출국 D-180 타임라인. 대행업체는 출국 직전 검색을 광고비로 사야 하지만, 우리는 입사 첫날부터 그 근로자를 안다(CAC 0). 적립 대시보드는 재직 데이터 없이는 물리적으로 못 만든다.

무력화 → refundcheck·케이비자·HRD 관영
통합 화면 0건
E2락인 · 원천

Employer-Verified Data Loop — 엣지의 엣지

VisaDesk 기업 원장 → 근로자 프로필 사전 채움 → 기업 확인 버튼(월 1회 원클릭 검증) → 월간 freshness. 한패스·클링커즈의 데이터는 자기신고+행태 — 금융권이 원하는 건 기업·근로자 양쪽에서 검증된 최신 신호다. B2B 준법 SaaS를 먼저 팔아야만 생기는 자산.

무력화 → 한패스·클링커즈·NICE Welko
공급자 0 (SSOT)
E3락인

E-7-4 전환 스튜디오 — 백지 1호 선점

E-9→E-7-4 점수 자동판정(원장 데이터로 70% 자동) + 부족점수 로드맵 + 본인 제출용 전환 준비 체크리스트 + 기업용 "핵심 인력 유지" 뷰. 점수제 제도화(107개 지역)의 정책 순풍을 받는 유료 상품이 아직 0건. 전환 성공 = 데이터 수명 3~5년 연장. 제출 라우팅은 출입국민원 대행기관 등록 행정사·변호사 한정.

무력화 → 자블리·행정사·K-Work
유료 상품화 백지 0건
E4수익화

Financial Passport 신호 API — 수익 엔진

점수·등급 없이 동의 기반 재직·소득·체류 검증 신호를 표준 스키마 12필드로 금융권에 제공. 동의센터(금융사·필드별 동의/철회)+감사로그. 송금 행태로는 "고용주가 검증한 재직·임금"을 못 만든다 — JB 계좌개설 교착('26.3)이 이 신호의 정책 수요를 방증.

무력화 → 한패스 대안신용·vivisa ACSS
재직·임금 신호 공급 0
E5입구 · 신뢰

Rights Guard — 신뢰 앵커, 백지 2호

임금체불·부당공제·산재 다국어 셀프 체크(급여 데이터 사실 대조 — "진단·판정"형 문구 금지) → 정부 무료 채널 우선 안내 + 전문가 라우팅 + 진행상태 표시·알림. 민간 디지털 서비스 전무. "내 데이터가 팔린다"는 불신을 상쇄하는 동의율 해자 장치 — E4의 전제 조건.

무력화 → (정부 채널만 존재)
민간 리걸테크 전무
E6수익화

Expert Partner Desk — 대행사를 고객으로

행정사·노무사에게 "사전 정리 서류 패키지(Document-Ready)"(동의 기반 증빙 정리+다국어 커뮤니케이션)를 공급. 케이비자의 파트너스는 접수처 유통망일 뿐 — 우리는 반대로 데이터를 들고 전문가망(행정사 3,360)을 유통망으로 흡수한다. refundcheck 같은 1인 행정사가 잠재 고객. 과금은 수임 여부와 무관한 용역 fee만(성공보수 연동 금지).

E1·E5 없이 E4만 →
